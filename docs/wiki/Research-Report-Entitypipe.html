In plain wordsIn einfachen Worten

This report builds a pipeline that turns an existing map of Wolfenstein II: The New Colossus (the Gestapo office) into a custom map by editing its text-based entity file. It changes 49 things a player would notice: tougher enemies, food pickups turned into weapons and ammo, red and green lights, and swapped spawn points. The rebuilt archive passes every offline check. Whether it loads in the game has not been confirmed.

  • The entity reader and writer round-trip 85 of 85 entity files byte-exactly.
  • 49 entities are changed: 4 enemies (for example 3 light soldiers become heavy elites), 10 pickups, 33 lights and 2 spawn points.
  • Changes reuse enemy and item setups that already exist in the same map, so no new assets are needed.
  • The checker rejects 8 of 8 broken test cases; all 7,127 other archive entries stay unchanged.
  • Runtime is unconfirmed; the page includes a short install-and-test runbook.

Result in one sentence

re_probes/entitypipe/base/chunk_22.resources is the alias map game/dlc/c02/c2v1_custom with 49 modified Entities across four classes (Enemies, Pickups, Lights, Spawn). It consists of probe_datahash 7127/7127, probe_idclhash +0x08/+0x20 OK, and the custom checker. A diff check allows only the 49 claimed Entities as modified, and none of the other 7127 entries are changed except the .entities entry. Structurally valid after these checks; runtime unconfirmed.

2. Format -- Text, no binary format

compfile:maps/game/dlc/c02/c2v1_custom.entities = 16 bytes (usize, csize) + Kraken; therein text. The 411,568 lines of Retail c2v1.entities are exactly five forms: 2 headers (Version 5, HierarchyVersion 2), 103,461 <kopf> {, 103,461 }, 204,499 schluessel = wert;, 145 quoted layer names. Indentation is not depth (the } of entityDef stands one level further left), therefore each node remembers its tabs -- hence byte-exact instead of just equivalent. The alias source brings two non-Retail single lines from codex (lightColor = { r = 0.05; g = 0.8; b = 1; }); exactly this form is accepted, in Retail it occurs 0 times.

8 of the 85 files are not valid UTF-8 (name = "break\xa8" in c09p1, c09p2, c1v3, c1v3_venus, each with patch copies); surrogateescape carries the byte unchanged through.

4. The Changes -- what a player sees

Every type change is a Body Transplantation from a donor existing within c2v1 itself: edit {} is a full property dump, a new inherit alone changes nothing visible. Name, Position, Orientation, targets, and bindParent remain from the target. Since every donor is already in the map, Models, Sounds, and Decls are in the mounted chunks, and the Builder breaks if a new name appears. Measured: no transplanted body carries a reference from the donor area, every Soldier keeps its own Roam point (roam_22/30/61/5).

4.3 Lights (33)

All LIGHT_POINT (16) and LIGHT_SPOT (17) within the range of both Spawn Points: Lobby has 18 red lights (1, 0.12, 0.05), Office has 18 green lights (0.15, 1, 0.35), intensity at least 4 each (raised to 26). Spotlights and ambient light remain untouched.

4.4 Spawn (2)

c2v1 has exactly two idPlayerStart: sacramento_gameplay_player_start_1 (Lobby, -18.3/-205.9) and c2v1_ps_challenge_01 (Office, 29.1/-77.2). Which one applies on a map call is undecidable offline: the chapter variant dlc/c2v1 requires spawnSpot = "c2v1_gameplay_player_start_1", a name that neither Retail nor Alias Entities contain (0 hits); the Challenge variant requires c2v1_ps_challenge_01. The two starts therefore swap places: whichever the Engine picks, the player stands at the Retail location of the other. Both locations are spots where the game itself spawns a player; they are the only offline evidence for fixed ground. Side effect: the room in which you wake up reveals which start the Engine chose.

5. What Remains Open

  • Runtime. Nothing is seen in-game. The bundle inherits all open points from the Alias bundle (Mount of dlc_4, Alias names, load path via the resourceExec carrier, whose Mount timestamp in the main menu is unrecorded, see execcarrier.md §4), which itself was never loaded.
  • Mission Logic. Kiscule scripts can hang at Lobby Start (idKisculeNodePlayerStartNotification exists in the Exe). If the player starts in the Office, Intro/Objectives may be missed; combat and pickups are unaffected.
  • Lights. Direct light from point/spotlights is calculated at runtime; baked portions (Spotlights, Lightmaps) remain Retail-colored. How strongly the color shift affects gameplay is untested.
  • Spawners and Type. Whether idTarget_AISpawn generates a different enemy type under the same name without further checks has not been verified via disassembly. Whether the Navmesh in the Commander area is designed for the large Super Soldier is unverified offline (the donor stands 39 m further south, at -69.3). The Super Soldier brings spawnSleepingDuration = -1 from its donor.
  • New Enemies instead of Type Conversion (Increase count) is not built: a new Entity name must also appear in a Spawner's targets, and whether the Engine requires more Pool/Streaming budget (.mapresources) for more instances is unrecorded. Type conversion and relocation work without new names.
  • --roundtrip takes ~10 min (82 files at ~10 MB each in pure Python).

6. Reproduction

python tools/build_custom_map.py                  # builds re_probes/entitypipe/ (~4 min)
python tools/probe_entitypipe.py --roundtrip      # 85/85 byte-exact
python tools/probe_entitypipe.py --surgical       # 1 line Diff
python tools/probe_entitypipe.py --negative       # 8/8
python tools/probe_entitypipe.py --bundle         # Hash samples, manipulation, table and entity diff (~2-6 min)

Runbook

  1. Install (PowerShell, Repo root; delete first, then copy to avoid writing via a hardlink in DLC2): $G="<Steam library>\steamapps\common\Wolfenstein.II.The.New.Colossus"; Remove-Item "$G\dlc\dlc_4\base\chunk_22.resources"; Copy-Item re_probes\entitypipe\base\chunk_22.resources "$G\dlc\dlc_4\base\"; python tools/install_exec_carrier.py install
  2. Start: Launch the game with +com_enableDeveloperMode 1, then in the main menu console: resourceExec wolfsdk_test.cfg (loads map game/dlc/c02/c2v1_custom; remains silent, use resourceExec wolfsdk_test.cfg -s).
  3. Observe: Wake up in the red-lit entrance area or the green-lit office (the room reveals which start the engine took); in the office lies a soldier's helmet 4 meters away, and in the lobby at (-3, -176) there is an MP instead of a pretzel, and the first lobby wave brings 3 heavy elite soldiers.
  4. Has worked if the map loads and the lights at spawn are red/green. If it loads with retail colors, our container is not being read; if it does not load at all, repeat the same test with re_probes/idclwriter/chunk_22.resources (alias without our edits) to separate the alias layer from the entity edit; if can't generate in production appears, the Traeger chunk was not mounted (execcarrier.md §4).
  5. Uninstall: Remove-Item "$G\dlc\dlc_4\base\chunk_22.resources"; Copy-Item "$G\dlc\dlc_2\base\chunk_22.resources" "$G\dlc\dlc_4\base\"; python tools/install_exec_carrier.py uninstall -- restores the current state (the installed dlc_4 chunk today is byte-identical to dlc_2 per cmp).
