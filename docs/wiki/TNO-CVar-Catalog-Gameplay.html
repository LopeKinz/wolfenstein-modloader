In plain wordsIn einfachen Worten

This page lists 976 of The New Order's cvars that deal with gameplay: game rules (g_), enemy AI (ai_), player movement (pm_), ragdoll physics (af_), animation and the view. Each row shows the type, the default value, its status (cheat, normal, saved, start-up-only or read-only), the allowed range where the game defines one, and the developers' own description.

  • 976 cvars: g_ (386), ai_ (221), pm_ (140), af_ (84), anim_ (31), view_ (31) and more.
  • 950 of them are cheats and need the 'toggle' route from the catalogue's start page.
  • Not cheats, so +name value works: g_permaGodMode, g_permaInfiniteAmmo, g_damageScale, g_fov, g_showHud and pm_togglesprint. All but g_fov are 'saved': the game keeps their value in its config file.
  • g_fov defaults to 80 and allows 10 to 100.
