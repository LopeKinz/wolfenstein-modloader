Offline Save Repair v3

Partly solvedTeilweise gelöst Original page in the GitHub wikiOriginalseite im GitHub-Wiki

In plain wordsIn einfachen Worten

This short report covers version 3 of the offline repair of a custom-map save game for Wolfenstein II: The New Colossus. The checksum in game.details turned out to be a CRC32 and matches all tested original files. Six outdated map length values were found and fixed. The repaired save was not written to the real save folder, so whether the game accepts it is still open.

  • The game.details CRC32 matches 26 original files with 21 different contents.
  • Six outdated map-start length values were reproduced and fixed.
  • Unchanged, longer and shorter name rebuilds are byte-exact.
  • Negative tests catch wrong lengths even when the file hashes look valid.
  • .verify files were left unchanged; acceptance in the running game is not yet tested.

Dieser Kurzbericht behandelt Version 3 der Offline-Reparatur eines Spielstands für eine eigene Karte in Wolfenstein II: The New Colossus. Die Prüfsumme in game.details ist ein CRC32 und passt zu allen getesteten Originaldateien. Sechs veraltete Längenwerte für Kartennamen wurden gefunden und korrigiert. Der reparierte Spielstand wurde nicht in den echten Speicherordner geschrieben; ob das Spiel ihn annimmt, ist daher noch offen.

  • Die CRC32 in game.details passt zu 26 Originaldateien mit 21 verschiedenen Inhalten.
  • Sechs veraltete Längenwerte im Kartenstart wurden nachgestellt und korrigiert.
  • Neubau mit unverändertem, längerem und kürzerem Namen ist byte-genau.

  • .verify-Dateien blieben unverändert; die Annahme im laufenden Spiel ist noch nicht getestet.

The original worker was terminated due to a usage limit. Astra resumed the work and verified it locally. The game.details CRC32 matches 26 original file paths / 21 distinct contents. Six stale map start lengths were reproduced and fixed. Identity and longer/shorter roundtrips are byte-exact; negative controls detect false lengths despite valid DAT hashes and stale CRCs.

Code: tools/probe_details_checksum.py, tools/build_custom_save_candidate.py, tools/verify_custom_save_candidate.py. Isolated result: re_probes/custom_save_candidates/FC2-WOLF0-c2v1_custom_v3.

No live save written. .verify unchanged, runtime acceptance open. Overall finding: docs/tnc_astra_findings_20260923.md.
