  1. Conscious Limitation

In plain wordsIn einfachen Worten

This page describes a prototype for a new map name ('c3v1_custom') in Wolfenstein II: The New Colossus, built from an original DLC archive without changing the game installation. It lists 243 assets, 210 of which are needed for the map. The page states plainly that this is not yet a working custom map: the main archive and texture database files are missing, and internal references still point to the old names. Starting the game with it would therefore not be a valid test.

  • New map alias: game/dlc/c03/c3v1_custom.
  • Inventory: 243 name-based assets, 210 of them map-critical.
  • chunk_26.resources and chunk_26.texdb are intentionally missing.
  • Internal references (geometry, collision, navigation, shadows, entities) are not yet renamed.
  • Only a complete, renamed set may be tested, and only in an isolated search path.

Generated from the authentic DLC-3 archive without modifying the Steam installation.

  • Alias: game/dlc/c03/c3v1_custom
  • Mapspec: base/packagemapspec.json (Chunk 26)
  • Inventory: 243 name-based assets, of which 210 are map-critical assets
  • Source: D:\SteamLibrary\steamapps\common\Wolfenstein.II.The.New.Colossus\dlc\dlc_2\base\chunk_22.resources (read-only)

Conscious Limitation

This is not yet a runnable Custom Map bundle. chunk_26.resources and chunk_26.texdb are intentionally missing. Furthermore, internal references (Proc, World-Tome, Collision, Navmesh, PVS, Shadow, and Entities) have not been byte-for-byte rewritten to c3v1_custom. Therefore, a start test would not constitute a valid map test.

bundle_status.json contains the negative controls. Only a complete, renamed Chunk/Texdb set may be copied into an isolated search path.
