This page lists 804 of Wolfenstein II's cvars that deal with gameplay: game rules (g_), player movement (pm_), the HUD, the view and camera, points of interest and enemy AI. Each row shows the type, the default value, whether the normal console accepts it, and the developers' own description. How to change a setting is explained on the catalogue's start page.

  • 804 cvars, grouped by name prefix: g_ (286), pm_ (88), hud_ (86), view_ (85), poi_ (54), ai_ (42) and more.
  • Only 14 of them are open to the normal console, among them g_fov, g_showHud, hud_disableAll and pm_togglesprint.
  • Cheats like g_infiniteAmmo are here too; they need the resourceExec route described on the start page.
  • Descriptions are the game's own help texts, not guesses.
