In plain wordsIn einfachen Worten

This page lists 2,231 names that look like engine settings (cvars), scraped as text from the Wolfenstein II: The New Colossus program file. The page itself warns that it is not a real catalog: only about 10 % of the names are genuine registered settings, and the running game reports just 304. The descriptions were matched to names by shared words, not read from the game code, so many are wrong. For modding, use the validated catalog first and treat this page only as a place to search for names.

  • 2,231 candidate names, sorted by prefix such as r_ (828), s_ (369) and g_ (284).
  • Hit rate is about 10 %; the engine itself lists 304 cvars, 82 of them missing here.
  • 1,374 names have a description, but these were guessed by word overlap, not confirmed.
  • Default values are missing entirely.
  • Part 1 settings such as com_allowConsole and pm_noBob do not exist in Wolfenstein II.

Technical detailsTechnische Details

Der technische Teil ist auf Englisch – so, wie er im Wiki steht. Unterstrichene Begriffe haben eine Erklärung auf Deutsch.

This is a candidate list, not a Cvar catalog. Of the 2,231 names listed here, there are 2,222 genuine, registered Cvars — a hit rate of 10 %. The engine itself reports via listCvars that there are 304 Cvars, 82 of which do not appear in this list. Of the assigned descriptions, 1,224 depend on names that are not Cvars. The reliable catalog is located in TNC-CVar-Validation.md and cvars_tnc_echt.json — check there first. This file remains useful only as a name pool for searching, nothing more.

2,231 cvar-like strings scraped from NewColossus_x64vk.exe. 1,374 have an assigned description; 1,013 of these contain at least two words from the name. 31 carry a value that appears in a genuine .cfg file of the game.

Generated by tools/mine_cvars_tnc.py.

How reliable is this? The names are solid: they are real strings within the program. The descriptions are assigned, not read — the game's .text is DRM-encrypted, so there is no call site that definitively links a name and description. Assignments rely on word overlap; [2] following an entry means two words from the name appear in the description, [1] means only one. Default values are entirely missing — they are shared short literals ("0", "1") without binding to their Cvar.

Not transferable from Part 1. com_allowConsole and pm_noBob do not exist here.
