In plain wordsIn einfachen Worten

The WolfSDK Loader is a free mod manager for Wolfenstein: The New Order and Wolfenstein II: The New Colossus (Steam versions on Windows only). You switch mods on in a local window (an app window of Edge or Chrome; nothing goes online), click Apply mods and start the game; settings are saved at once, there is no Save button; Revert puts the original game files back from the loader's backups. It also sets cvars for cheats and quality of life, offers graphics presets for The New Colossus and installs custom maps for that game. It shows new releases at the top right. The page marks every feature as confirmed in game or not yet confirmed in game.

  • Confirmed in game: applying and reverting mods with backups, and installing a custom map.
  • Both downloads contain 24 mods (8 for The New Colossus, 16 for The New Order); most are only checked structurally, not confirmed in game.
  • The complete cvar lists have 3,116 entries for The New Colossus and 3,186 for The New Order (before 0.3.0 only 31 measured tweaks for The New Order); the presets Ultra+ (17 cvars), Clean Image (11) and Photo Mode (3) are not yet confirmed in game.
  • In The New Colossus a bound key runs restricted, so the loader sets no F-keys there; Sandbox Tools (god mode and infinite ammo confirmed in game) and Photo Mode bind a key to resourceExec instead.
  • Maps loading from the developer menu and the mod test map loading are confirmed in game; the 126 developer start points and Hidden Menu Options are not yet.

WolfSDK Loader

Loader: what the WolfSDK Loader is (player guide)

The WolfSDK Loader is the mod manager for players of Wolfenstein: The New Order and Wolfenstein II: The New Colossus. You tick mods, apply them to the game, start the game and revert everything to the original. It also sets cheat and quality-of-life cvars and installs custom maps for The New Colossus. Version 0.3.0, free, MIT license, Windows and Steam versions only. This page is the player guide; modders read WolfSDK Studio.

Status labels on this page: Confirmed in game (seen working in the running game), Not yet confirmed in game (built and checked, not yet seen working in the game), Held back (built, but switched off in a release).

Keywords: wolfsdk loader, mod loader, mod manager, what is the loader, player guide, wolfenstein mods, new order, new colossus, tno, tnc, was ist der loader, anleitung für spieler

Loader: download WolfSDK 0.3.0 (Loader ZIP or Studio ZIP)

WolfSDK 0.3.0 is the current release: release page.

  • WolfSDK-Loader-0.3.0.zip is for players: mods, Cheats & QoL, presets, custom map install.
  • WolfSDK-Studio-0.3.0.zip is for modders: the same Loader plus the Studio.

Both need Windows and the Steam version of the game. Python is bundled, so you install nothing else. The source code is in the repository folder modloader/.

Keywords: download, release, wolfsdk 0.3.0, zip, which zip, loader zip, studio zip, where to get it, latest version, herunterladen, welche datei, neueste version

Loader: install and start WolfSDK (unzip, WolfSDK.cmd)

  1. Right-click the ZIP → Extract All… into a normal folder, for example Documents\WolfSDK. Do not run it from inside the ZIP and do not use C:\Program Files: the loader saves its settings in its own folder.
  2. Double-click WolfSDK.cmd. A black window flashes, then the loader opens in its own window.
  3. The loader finds the games through Steam. If it does not, open the game menu at the top left and choose Choose folder…, or click the folder icon at the top right.
  4. If Windows says "Windows protected your PC", click More info → Run anyway.

Later, a double-click on Spielen.cmd ("play") is enough: it applies the ticked mods if needed and starts the game.

Keywords: install wolfsdk, setup, unzip, extract, WolfSDK.cmd, Spielen.cmd, first start, smartscreen, windows protected your pc, choose folder, entpacken, einrichten, loader starten

Loader: the window and the tabs (Overview, Cheats & QoL, Mods, Studio, Info)

Since 0.3.0 the loader window is a local web page that the loader serves itself (127.0.0.1, nothing goes online). It opens as its own app window of Microsoft Edge (it comes with Windows), else Chrome, else a tab in your default browser. The old window still exists: python\python.exe -m wolfsdk gui --classic.

The top bar shows the WOLFSDK logo, a game menu button with the selected game and its engine (id Tech 5 or id Tech 6), the install path and, when there is an update, a green "Update X.Y.Z available" pill. The game menu lists the installed games and Choose folder… for an install the loader did not find; the folder icon button on the right does the same. Below it are five tabs:

  • Overview: install status, three numbers, quick actions and the custom map card.
  • Cheats & QoL: the searchable cvar lists and, for The New Colossus, the presets.
  • Mods: the mods of the selected game (with the number of active mods), to switch on and off.
  • Studio: Open Studio (only in the Studio package).
  • Info: updates, support link, console commands, key binds and notes.

The play bar at the bottom of every page shows a coloured status dot with the install state and the last message, an Activity button (the results of checks, applies and starts), Revert, Apply mods and Start game. There is no Save button: switches and values are saved the moment you change them (in config.json, as before, so Spielen.cmd uses them). While the ticked mods are not in the game files yet, Apply mods is highlighted with an amber dot.

Keywords: tabs, loader window, gui, interface, buttons, overview tab, mods tab, cheats tab, console tab, studio tab, reiter, oberfläche, fenster, knöpfe

Loader: Overview tab (install status and quick actions)

The Install status card shows the state of the selected game and a hint:

  • "Original state · ready": no mods are in the game files.
  • "Mod set active · backup in place": mods are applied and the backup is intact; "In sync with the game" means the ticked mods are the applied ones.
  • "Changes not applied yet": you changed the ticked mods; click Apply mods.
  • "Recovery needed": the last apply or revert was interrupted. Click Revert.

Three numbers follow: Active mods (n of total), Tweaks (cvars set) and Archives (Ready or Launch only). Quick actions has Manage mods, Check mod set and Mods folder. For The New Colossus the Custom map card has Install map… and Remove map. Short safety notes sit below: the loader runs locally, injects no DLL, makes bit-exact backups and keeps a write-ahead journal.

Keywords: overview, dashboard, install status, original state, mod set active, recovery needed, quick actions, game status, übersicht, zustand, status

Loader: Mods tab (tick mods, search, read descriptions)

The Mods tab lists only the mods of the selected game. Each row has a switch. Search filters by name, id, author and description; the filter shows All, Active or Inactive mods. All on and All off switch everything or nothing, and there are buttons to rescan the mods folder, open it and Check. Click a row (not its switch) to see the mod's details in the panel on the right: version, priority, assets, cvars, author and description, which says what the mod does and whether it is tested. The panel has a Turn on / Turn off button. The Activity button in the play bar shows the results of Check, Apply mods and Revert.

Switching a mod on changes nothing in the game yet: click Apply mods afterwards.

Keywords: mods tab, mod list, tick mod, select mods, choose mods, search mods, mod description, all on, all off, mod auswählen, anhaken, mods ankreuzen

Loader: add a new mod folder (open the mods folder, rescan)

A mod is a folder with a mod.json file. To add a mod you downloaded:

  1. On the Mods tab click the button that opens the mods folder (or Mods folder on the Overview). This opens the loader's mods folder.
  2. Copy the mod's folder into it, so that mods\<name>\mod.json exists.
  3. Click the rescan button. The mod appears if it is made for the selected game.
  4. Switch it on and click Apply mods.

Mods saved by the Studio land in the same folder; rescan to see them. The file format is described on Mod Format.

Keywords: add mod, new mod, downloaded mod, mods folder, mod.json, open folder, reload, rescan, mod not showing, mod not listed, mod hinzufügen, mod ordner, neue mod

Loader: how to install mods (Apply mods)

Applying is how you install mods: the loader writes the ticked mods into the game's archives and backs up everything first.

  1. Close the game.
  2. Switch the mods on in the Mods tab.
  3. Click Apply mods. "N asset(s) patched." in the Activity list means the mods are applied.
  4. Click Start game.

Each apply reverts first and then applies the whole ticked set again, so applying twice is safe. Applying closes an open Studio. With no mod ticked, Apply mods reverts the game.

Status: Confirmed in game.

Keywords: apply mods, applying mods, install mods, install a mod, enable mods, load mods, use mods, add mods, patch the game, mods anwenden, mods installieren, wie installiere ich mods

Loader: check mods before applying (Check mod set)

Check mod set on the Overview tab, or Check on the Mods tab, tests the ticked mods and writes nothing. It checks asset names, conflicts between mods and the backup. Typical answers:

  • "No conflicts. Ready to apply."
  • "N conflict(s); higher priority wins."
  • "Your selection is out of sync with the game.": the ticked mods differ from the applied ones; Apply mods fixes that.
  • "Check failed — nothing was changed." with the error, for example two mods that change the same textures.

Keywords: check mods, check mod set, test mods, conflicts, compatible mods, out of sync, mods prüfen, konflikt, kompatibel, vorab prüfen

Loader: undo all mods (Revert)

Revert undoes every mod change and restores the original game files bit for bit from the loader's backups. Since 0.3.0 this includes replaced sound packs and video files. Close the game, click Revert and confirm "Undo all mod changes and restore the original game files?". The message "The game is back to its original state." means it is done. Each game has its own backups and its own Revert. Revert also removes the cvars the loader wrote into The New Colossus' default.cfg.

Last resort, if the backups are gone: in Steam, Properties → Installed Files → Verify integrity of game files.

Status: Confirmed in game.

Keywords: revert, undo mods, remove mods, uninstall mods, disable mods, restore original, reset game, rollback, mods rückgängig machen, zurücksetzen, mods entfernen, deinstallieren

Loader: start the game (Start game)

Start game starts the game through Steam with the cvars from Cheats & QoL and from the ticked mods (your settings are already saved). If the ticked mods are not in the game files yet, it asks "Mods not in the game yet" with Cancel, Start without and Apply and start: choose the last one, otherwise the game starts with the old mod set. Spielen.cmd does the same without opening the window.

Applied mods stay in the game files, so a start from the Steam library has them too. The cvars that the loader passes as start arguments only come with Start game or Spielen.cmd.

Keywords: start game, launch game, play, run game, steam, Spielen.cmd, starts without mods, cvars missing, spiel starten, spielen, starten

Loader: backups and safety net (journal, _wolfsdk_backup)

Before it writes, the loader saves the original data of everything an apply changes. The backups are in the game's base folder: _wolfsdk_backup for The New Order, _wolfsdk_tnc for The New Colossus. Do not delete them while mods are applied. A write-ahead journal lets Revert finish an apply that a crash or power cut interrupted ("Recovery needed" on the Overview tab). A lock stops two apply or revert runs at the same time. The backups need about 1 GB free on the game's drive, with The New Order up to about 3 GB depending on the mods.

Keywords: backup, journal, _wolfsdk_backup, _wolfsdk_tnc, safety, crash during apply, power cut, disk space, sicherung, sicherheitskopie, absturz, stromausfall

Loader: what to do after a game update

The game must be closed while the loader applies or reverts mods. After a game update, click Revert first, then Apply mods again. The last resort, if the original files cannot be restored: in Steam, Properties → Installed Files → Verify integrity of game files, then apply the mods again.

Keywords: game update, steam update, after update, mods broken after update, verify integrity, spiel update, nach dem update, aktualisierung

Cheats & QoL: set cvars (cheats, graphics, quality of life)

The Cheats & QoL tab lists the complete cvar lists with the game's descriptions: all 3,186 settable cvars of The New Order's engine registry and all 3,116 of The New Colossus. (Before 0.3.0 The New Order showed only the 31 measured tweaks; these still come first.) Search by cvar name or description, pick a category, or use the "Only set" filter; a count is shown. On/off cvars have switches, numbers and text have value boxes, choices have drop-downs. Small chips mark a "cheat" (The New Order: also sent as +toggle at start) and "via default.cfg" (The New Colossus: not a retail command, delivered through default.cfg on the next apply or start). Type extra lines in the Custom cvars box at the bottom, for example pm_runspeed 400; everything is saved as you type.

  • The New Order: passed when the game starts; no file changes. Cheat cvars are also sent as +toggle, so the startup cheat reset does not wipe them.
  • The New Colossus: cvars the retail console accepts go as start arguments; the rest go into default.cfg with the next apply. Revert removes them.

Status: Not yet confirmed in game (the +toggle route, the default.cfg route and The New Order cvars beyond the 31 measured tweaks).

Keywords: cheats, cvars, console variables, qol, tweaks, fov, graphics settings, custom cvars, cheats aktivieren, einstellungen, konsolenvariablen

Cheats & QoL: presets Ultra+, Clean Image and Photo Mode (Apply preset)

Presets exist for The New Colossus only, on the Cheats & QoL tab:

  • Ultra+ (17 cvars): sharper texture filtering, more texture streaming, longer decal, shadow and foliage distances, better water.
  • Clean Image (11): no depth of field, motion blur, chromatic aberration, film grain or vignette, no resolution scaling, plus sharpening.
  • Photo Mode (3): screenshot quality only.

Pick one and click Apply preset: it fills in the values and they are saved at once; Start game or Apply mods delivers them. Reset takes the values back.

Status: Not yet confirmed in game.

Keywords: presets, ultra, ultra+, clean image, photo mode preset, graphics preset, better graphics, apply preset, reset preset, grafik, voreinstellung, grafik verbessern

Info tab: The New Order console (Ctrl+^) and F1–F4 keys

In The New Order the console opens with Ctrl+^ (Ctrl and the key left of 1); no setting is needed. The Info tab lists the console commands (with copy buttons), key bindings and notes. Useful commands are such as toggle g_permaGodMode 0 1 (god mode), toggle g_infiniteAmmo 0 1, toggle g_freeCam 0 1 (free camera), killMonsters and devmap. The loader also binds four keys in The New Order: F1 god mode, F2 infinite ammo, F3 free camera, F4 HUD on/off.

Status: Not yet confirmed in game (console with Ctrl+^, +toggle cheat cvars, F1–F4 binds).

Keywords: console, open console, new order console, ctrl+^, god mode, free camera, f1, f2, f3, f4, key binds, konsole öffnen, cheats tno, tasten

The New Colossus: no default F-key binds (use Sandbox Tools)

The loader gives The New Colossus no default F-key binds. A key bound in that game runs at a restricted console level, where toggle and noclip do not exist. The mods for The New Colossus use resourceExec <cfg> -s instead: the key runs a config file that the mod put into the game's archives, and that file can use the hidden commands. You bind such a key once in the game's console; binds are saved. For god mode and infinite ammo use the Sandbox Tools mod, for screenshots the Photo Mode mod.

Keywords: tnc keys, f keys, hotkeys, key bind, bind, resourceExec, restricted console, f1 does nothing, tastenbelegung, tasten belegen, new colossus konsole

Shipped mods: which mods come with WolfSDK

Both ZIPs contain 24 mods in the mods folder: 8 for The New Colossus and 16 for The New Order. All are off until you tick them.

  • The New Colossus: Sandbox Tools, Dev Menu Map Loading, Hidden Menu Options, Photo Mode, Explosive Pistol, Golden Pistol (Simple), Invulnerable (TNC), Gore Enhanced (TNC).
  • The New Order: five example mods, four gore mods, five gameplay mods and two sound mods.

Most shipped mods are only checked structurally. Unless a mod's description in the loader says otherwise, treat it as not yet confirmed in game. Four mods that carry whole modified retail files are left out of the package: gore textures, the supersoldiers map, the golden pistol with textures and the menu branding.

Mod: Sandbox Tools (god mode, Notarget, infinite ammo, kill all enemies)

For The New Colossus. F6 toggles god mode, Notarget and infinite ammo; F7 kills all enemies. Tick the mod, click Apply mods, start the game and bind the keys once in the game's console (binds are saved):

bind F6 "resourceExec snapdemo.cfg -s"
bind F7 "resourceExec snapedit.cfg -s"

The mod uses two unused SnapMap configs.

Status: god mode and infinite ammo: Confirmed in game. Notarget and F7: Not yet confirmed in game; in the test, Notarget did not stop enemies that were already fighting you.

Keywords: sandbox tools, god mode, godmode, invincible, notarget, infinite ammo, unlimited ammo, kill all enemies, killMonsters, f6, f7, cheats tnc, unsterblich, unendlich munition

Mod: Dev Menu Map Loading (developer menu loads maps again)

For The New Colossus. In the retail game the developer menu's map entries do not load maps. With this mod each map entry runs devmap with its spawn spot and layers, so the map loads. 126 entries also get their developer start point (dev teleport) back. Not included: chapter progression, the give lines and the DLC maps' dev teleports. The menu also lists "WolfSDK: Mod test map" and "WolfSDK: Box"; both need maps this package does not build yet.

Status: loading maps from the developer menu: Confirmed in game. The 126 developer start points: Not yet confirmed in game.

Keywords: dev menu map loading, developer menu, devmenu, devmap, load map, level select, chapter select, dev start points, entwicklermenü, karte laden, levelauswahl

Mod: Hidden Menu Options (developer menu entry, SAS menu, Mein Leben!)

For The New Colossus. Turns on four menu options the retail game hides:

  • the main menu entry to the developer menu (menu_showOptionForDevMenu),
  • the SAS menu entry (menu_showOptionForSASMenu),
  • the hardest difficulty Mein Leben! without finishing the game first (menu_allowMeinLeben),
  • the photo mode setting (g_setting_photomode); what it does in this game is unknown.

The console refuses these developer cvars, so the loader writes them into the game's default.cfg when you click Apply mods.

Status: Not yet confirmed in game.

Keywords: hidden menu options, hidden options, developer menu entry, sas menu, mein leben, hardest difficulty, unlock difficulty, versteckte optionen, schwierigkeitsgrad freischalten

Mod: Photo Mode (F8 freezes time with a free camera)

For The New Colossus. One key freezes the game for screenshots: time stops, the free camera turns on, and the HUD, menus and crosshair disappear. Press it again to return. Tick the mod, click Apply mods, start the game and bind the key once in the console (binds are saved):

bind F8 "resourceExec default_snap.cfg -s"

It uses the unused SnapMap config default_snap.cfg. It is not the same as the Photo Mode preset on Cheats & QoL, which only raises screenshot quality.

Status: Not yet confirmed in game.

Keywords: photo mode, photomode, f8, freeze time, free camera, hide hud, screenshots, fotomodus, freie kamera, hud ausblenden

Mods: Explosive Pistol and Golden Pistol (Simple) for The New Colossus

Explosive Pistol: the standard pistol fires the rocket of the Kampfpistole, which explodes on impact, and the magazine holds 30 instead of 10 rounds. It takes over the launcher's sound, recoil and direct-hit damage; the silencer no longer makes it quiet. The rocket arms only after about 5 m; closer, it bounces off and goes off after 3 s. Status: 30-round magazine: Confirmed in game. Explosion: Not yet confirmed in game.

Golden Pistol (Simple): makes the standard pistol golden, in the campaign and in the DLC "Agent Silent Death", with material decls only. Do not tick it together with another skin for the pistol. Status: Not yet confirmed in game.

Keywords: explosive pistol, rocket pistol, kampfpistole, 30 rounds, magazine, golden pistol, gold skin, weapon skin, explosivpistole, goldene pistole, waffenskin

Mods: Invulnerable (TNC) and Gore Enhanced (TNC)

Invulnerable (TNC): sets the multiplier on the damage the player takes to 0 in all seven difficulty tables. It was the first mod for The New Colossus. Status: Not yet confirmed in game.

Gore Enhanced (TNC): raises the gore probability of the standard enemy behaviours. It was built from The New Colossus' own decls, never from The New Order's. Status: Not yet confirmed in game.

Keywords: invulnerable, no damage, take no damage, god mode mod, gore enhanced, more gore, blood, dismemberment tnc, unverwundbar, kein schaden, mehr gore

Mods for The New Order: the five example mods

Small mods that show how mods work:

  • Big Pistol Magazine (Example): pistol magazine 20 → 66; the HUD shows at once that mods arrive in the game.
  • Dev Loadout (Example): much more player health and air.
  • Faster Shotgun (Example): shorter firing intervals for the shotgun.
  • Weapon Tuning (Example): more damage for several weapons.
  • White Pistol (Skin Example): the standard pistol uses a white material that already exists in the game.

Status: Not yet confirmed in game (checked structurally).

Keywords: example mods, big magazine, dev loadout, faster shotgun, weapon tuning, white pistol, first mod, test mod, beispielmods, beispiel mod

Mods for The New Order: gore mods

  • More Realistic Gore: each weapon class gets its own gore table, with decapitation and torso split, tied to the damage dealt.
  • Gore Deep Layer: removes the melee block on the head zone, so knife kills bleed, and sets forceInjured on all 13 body zones.
  • Ultimate Gore - Hits, Voice, Physics, Lethality: more blood on hits, working blood pools, pain and death screams 4× as often, limper ragdolls, and enemies that die faster.
  • Ragdolls Stay Dismemberable: corpses keep reacting to hits and can be cut apart; ragdoll impulse +120%.

Status: Not yet confirmed in game (checked structurally).

Keywords: gore, blood, dismemberment, decapitation, ragdoll, realistic gore, brutal, more blood, gore mod tno, mehr blut, zerstückelung, blutiger

Mods for The New Order: gameplay mods

  • Cheats - Health and Ammo: the campaign gets the values of the 999 mode: 999 starting health, ammo is never used up, health above 100 does not drain.
  • Enigma - Bonus Modes Without Secrets: the four bonus modes need no Enigma secrets; whether the engine accepts "0 secrets" is unclear.
  • Factions - Panzerhunds Go Berserk: Panzerhunds should attack the enemies on their own side.
  • Resistance - Combat Overhaul: tougher, better armed enemies in chapter 6, a tougher player and a stronger pistol.
  • Aim Assist for All Weapons: aim assist for every player projectile, spread lowered to 40%.

Status: Not yet confirmed in game (checked structurally).

Custom map: install a map for The New Colossus (Install map…)

A custom map is a finished map file, chunk_22.resources, built by someone else; the loader cannot build maps. You need the DLC The Freedom Chronicles, episode 2.

  1. Close the game. If mods are applied, the loader usually asks for a Revert first.
  2. On the Overview tab, under Quick actions, click Install map… and choose the file.
  3. The loader sets it up as its own DLC folder dlc\dlc_0.
  4. In the game, load The Freedom Chronicles, episode 2: the custom map takes the place of the map c2v1.

Extra maps in the same file are loaded from the developer menu.

Status: Confirmed in game.

Keywords: custom map, install map, new map, map file, chunk_22.resources, dlc_0, freedom chronicles, c2v1, eigene karte, karte installieren, map installieren

Custom map: remove the map (Remove map)

On the Overview tab click Remove map and confirm. The loader deletes only what it put into dlc\dlc_0; afterwards episode 2 of The Freedom Chronicles loads the original map c2v1 again. A custom map folder in dlc_0 that was set up by hand is left alone: click Install map… once to let the loader take it over, then it can remove it too. Close the game first; if mods are applied, Revert first.

Troubleshooting: the loader does not start

  • Extract the ZIP first. Started from inside the ZIP, WolfSDK.cmd only tells you to extract it.
  • Do not put it under C:\Program Files; the loader saves its settings in its own folder.
  • "Windows protected your PC": click More info → Run anyway.
  • The black window usually stays open with the error message. The same text is in %LOCALAPPDATA%\wolfsdk\start.log.

Troubleshooting: the game is not found (Choose folder…)

The loader finds the Steam installs of both games by itself. If the Overview tab says "No game install found", open the game menu at the top left, choose Choose folder… (or click the folder icon at the top right) and pick the game's install folder. Only the Steam version works: the Microsoft Store/Game Pass version locks the game files, and GOG and Epic are untested. With both games installed, switch between them in the game menu at the top left.

Troubleshooting: a mod has no effect in the game

  • Ticking is not enough: click Apply mods, then start the game. Start game offers to apply first.
  • Check the game selected in the game menu; the Mods tab only shows that game's mods.
  • The Overview tab should say "Mod set active · backup in place" and "In sync with the game".
  • Mods for The New Colossus that use keys (Sandbox Tools, Photo Mode) need their bind line typed once in the game's console.
  • Many mods are not yet confirmed in game; read the mod's description on the Mods tab.

Troubleshooting: Apply mods or Revert is refused

  • The game is running: close it completely and try again.
  • Not enough disk space: the loader stops before it writes any mods (mods that were applied are reverted). Free about 1 GB on the game's drive, up to about 3 GB for The New Order.
  • "Recovery needed" or "Interrupted patch run - please revert.": an earlier run was cut off. Click Revert.
  • "Check failed — nothing was changed.": read the error in the Activity list; often two mods change the same textures.

Keywords: apply failed, revert failed, refused, cancelled, disk space, game running, interrupted, recovery needed, fehler beim anwenden, abgelehnt, abgebrochen

Troubleshooting: Install map… is refused

  • The DLC The Freedom Chronicles (episode 2, map c2v1) is not installed. Custom maps need it.
  • Mods are applied: click Revert, install or remove the map, then click Apply mods again.
  • dlc\dlc_0 belongs to something else: the loader leaves a folder it does not know alone.
  • The buttons are grey: Install map… and Remove map only work for The New Colossus.

Loader limits: Steam only, German version, one PC

  • Steam versions only. Microsoft Store/Game Pass does not work; GOG and Epic are untested.
  • The German, censored version has different textures. Skins made from the international version probably do not apply there; this is unverified.
  • Tested on one PC so far.
  • The loader cannot build maps; a custom map file has to come from someone who built it.
  • Do not tick two skins for the same weapon at the same time. The loader only refuses this by itself when both change the same textures.

Loader limits: save games and disk space

  • Back up your saves once before you use mods: copy the folder %USERPROFILE%\Saved Games\MachineGames. Whether old saves load cleanly with and without every mod has not been checked for every mod.
