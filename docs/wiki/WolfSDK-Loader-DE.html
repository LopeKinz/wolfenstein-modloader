In plain wordsIn einfachen Worten

The WolfSDK Loader is a free mod manager for Wolfenstein: The New Order and Wolfenstein II: The New Colossus (Steam versions on Windows only). You switch mods on in a local window (an app window of Edge or Chrome; nothing goes online), click Apply mods and start the game; settings are saved at once, there is no Save button; Revert puts the original game files back from the loader's backups. It also sets cvars for cheats and quality of life, offers graphics presets for The New Colossus and installs custom maps for that game. It shows new releases at the top right. The page marks every feature as confirmed in game or not yet confirmed in game.

  • Confirmed in game: applying and reverting mods with backups, and installing a custom map.
  • Both downloads contain 24 mods (8 for The New Colossus, 16 for The New Order); most are only checked structurally, not confirmed in game.
  • The complete cvar lists have 3,116 entries for The New Colossus and 3,186 for The New Order (before 0.3.0 only 31 measured tweaks for The New Order); the presets Ultra+ (17 cvars), Clean Image (11) and Photo Mode (3) are not yet confirmed in game.
  • In The New Colossus a bound key runs restricted, so the loader sets no F-keys there; Sandbox Tools (god mode and infinite ammo confirmed in game) and Photo Mode bind a key to resourceExec instead.
  • Maps loading from the developer menu and the mod test map loading are confirmed in game; the 126 developer start points and Hidden Menu Options are not yet.

Loader: was der WolfSDK Loader ist (Anleitung für Spieler)

Der WolfSDK Loader ist der Mod-Manager für Spieler von Wolfenstein: The New Order und Wolfenstein II: The New Colossus. Du hakst Mods an, wendest sie auf das Spiel an, startest das Spiel und setzt alles auf das Original zurück. Er setzt auch Cheat- und Komfort-Cvars und installiert eigene Karten für The New Colossus. Version 0.3.0, kostenlos, MIT-Lizenz, nur Windows und Steam-Versionen. Diese Seite ist die Anleitung für Spieler; Modder lesen WolfSDK Studio.

Status-Angaben auf dieser Seite: Im Spiel bestätigt (im laufenden Spiel funktionierend gesehen), Im Spiel noch nicht bestätigt (gebaut und geprüft, im Spiel noch nicht so gesehen), Zurückgehalten (gebaut, in einem Release aber abgeschaltet).

Loader: WolfSDK 0.3.0 herunterladen (Loader-ZIP oder Studio-ZIP)

WolfSDK 0.3.0 ist das aktuelle Release: Release-Seite.

  • WolfSDK-Studio-0.3.0.zip ist für Modder: derselbe Loader plus das Studio.

Beide brauchen Windows und die Steam-Version des Spiels. Python ist dabei, du installierst also nichts weiter. Der Quellcode liegt im Repository-Ordner modloader/.

Loader: WolfSDK installieren und starten (entpacken, WolfSDK.cmd)

  1. Rechtsklick auf die ZIP → Alle extrahieren… in einen normalen Ordner, zum Beispiel Dokumente\WolfSDK. Starte es nicht aus der ZIP heraus und nimm nicht C:\Program Files: Der Loader speichert seine Einstellungen im eigenen Ordner.
  2. Doppelklick auf WolfSDK.cmd. Ein schwarzes Fenster blitzt kurz auf, dann öffnet sich der Loader in einem eigenen Fenster.
  3. Der Loader findet die Spiele über Steam. Falls nicht, öffne oben links das Spielmenü und wähle Choose folder…, oder klicke oben rechts auf das Ordner-Symbol.
  4. Meldet Windows „Der Computer wurde durch Windows geschützt", klicke auf Weitere Informationen → Trotzdem ausführen.

Später reicht ein Doppelklick auf Spielen.cmd: Es wendet die angehakten Mods bei Bedarf an und startet das Spiel.

Keywords: wolfsdk installieren, einrichten, entpacken, extrahieren, WolfSDK.cmd, Spielen.cmd, erster start, smartscreen, windows geschützt, ordner wählen, loader starten, install, unzip, setup

Loader: das Fenster und die Reiter (Overview, Cheats & QoL, Mods, Studio, Info)

Seit 0.3.0 ist das Loader-Fenster eine lokale Webseite, die der Loader selbst ausliefert (127.0.0.1, nichts geht ins Internet). Sie öffnet sich als eigenes App-Fenster von Microsoft Edge (gehört zu Windows), sonst von Chrome, sonst als Tab im Standardbrowser. Das alte Fenster gibt es weiter: python\python.exe -m wolfsdk gui --classic.

Die obere Leiste zeigt das WOLFSDK-Logo, einen Spielmenü-Knopf mit dem gewählten Spiel und seiner Engine (id Tech 5 oder id Tech 6), den Installationspfad und, wenn es ein Update gibt, eine grüne Pille „Update X.Y.Z available". Das Spielmenü listet die installierten Spiele und Choose folder… für eine Installation, die der Loader nicht gefunden hat; der Ordner-Knopf rechts tut dasselbe. Darunter liegen fünf Reiter:

  • Overview: Installationszustand, drei Zahlen, Schnellaktionen und die Karte für eigene Karten.
  • Cheats & QoL: die durchsuchbaren Cvar-Listen und, für The New Colossus, die Presets.
  • Mods: die Mods des gewählten Spiels (mit der Zahl der aktiven Mods), zum An- und Ausschalten.
  • Studio: Open Studio (nur im Studio-Paket).
  • Info: Updates, Support-Link, Konsolenbefehle, Tastenbelegungen und Hinweise.

Die Play-Leiste unten auf jeder Seite zeigt einen farbigen Statuspunkt mit dem Installationszustand und der letzten Meldung, einen Activity-Knopf (die Ergebnisse von Prüfungen, Anwenden und Starts), Revert, Apply mods und Start game. Einen Save-Knopf gibt es nicht mehr: Schalter und Werte werden im Moment der Änderung gespeichert (in der config.json, wie bisher, also nutzt Spielen.cmd sie). Solange die angehakten Mods noch nicht in den Spieldateien sind, ist Apply mods hervorgehoben, mit einem bernsteinfarbenen Punkt.

Keywords: reiter, tabs, loader fenster, oberfläche, knöpfe, schaltflächen, overview, mods reiter, cheats reiter, console reiter, studio reiter, gui, interface, buttons

Loader: Reiter Overview (Installationszustand und Schnellaktionen)

Die Karte Install status zeigt den Zustand des gewählten Spiels und einen Hinweis:

  • „Original state · ready": Es sind keine Mods in den Spieldateien.
  • „Mod set active · backup in place": Mods sind angewendet, und die Sicherung ist intakt; „In sync with the game" heißt, die angehakten Mods sind die angewendeten.
  • „Changes not applied yet": Du hast die angehakten Mods geändert; klicke auf Apply mods.
  • „Recovery needed": Das letzte Anwenden oder Zurücksetzen wurde unterbrochen. Klicke auf Revert.

Darunter stehen drei Zahlen: Active mods (n von gesamt), Tweaks (gesetzte Cvars) und Archives (Ready oder Launch only). Quick actions enthält Manage mods, Check mod set und Mods folder. Für The New Colossus hat die Karte Custom map die Knöpfe Install map… und Remove map. Kurze Sicherheitshinweise stehen darunter: Der Loader läuft lokal, injiziert keine DLL, legt bitgenaue Sicherungen an und führt ein Write-Ahead-Journal.

Keywords: übersicht, overview, zustand, installationszustand, originalzustand, mod set active, recovery needed, schnellaktionen, quick actions, status, dashboard

Loader: Reiter Mods (Mods anhaken, suchen, Beschreibungen lesen)

Der Reiter Mods zeigt nur die Mods des gewählten Spiels. Jede Zeile hat einen Schalter. Die Suche filtert nach Name, ID, Autor und Beschreibung; der Filter zeigt Alle, Aktive oder Inaktive. All on und All off schalten alles oder nichts an, dazu gibt es Knöpfe, um den Mods-Ordner neu zu lesen, ihn zu öffnen und Check. Ein Klick auf eine Zeile (nicht auf den Schalter) zeigt die Details der Mod im Feld rechts: Version, Priorität, Assets, Cvars, Autor und Beschreibung, die sagt, was die Mod tut und ob sie getestet ist. Das Feld hat einen Knopf Turn on / Turn off. Der Knopf Activity in der Play-Leiste zeigt die Ergebnisse von Check, Apply mods und Revert.

Eine Mod einzuschalten ändert noch nichts am Spiel: Klicke danach auf Apply mods.

Keywords: mods reiter, mod liste, mod anhaken, mods auswählen, mods ankreuzen, mods suchen, mod beschreibung, all on, all off, mods tab, tick mod, select mods

Loader: einen neuen Mod-Ordner hinzufügen (Mods-Ordner öffnen, neu lesen)

Eine Mod ist ein Ordner mit einer Datei mod.json. So fügst du eine heruntergeladene Mod hinzu:

  1. Klicke im Reiter Mods auf den Knopf, der den Mods-Ordner öffnet (oder auf Mods folder in der Overview). Das öffnet den Ordner mods des Loaders.
  2. Kopiere den Ordner der Mod hinein, sodass mods\<name>\mod.json existiert.
  3. Klicke auf den Knopf zum Neu-Lesen. Die Mod erscheint, wenn sie für das gewählte Spiel gemacht ist.
  4. Schalte sie ein und klicke auf Apply mods.

Mods, die das Studio speichert, landen im selben Ordner; lies den Ordner neu, um sie zu sehen. Das Dateiformat beschreibt Mod Format.

Keywords: mod hinzufügen, neue mod, heruntergeladene mod, mods ordner, mod.json, open folder, reload, neu lesen, mod wird nicht angezeigt, mod fehlt in der liste, add mod, mods folder, mod not showing

Loader: wie installiere ich Mods (Apply mods)

Anwenden ist der Weg, Mods zu installieren: Der Loader schreibt die angehakten Mods in die Archive des Spiels und sichert vorher alles.

  1. Schließe das Spiel.
  2. Schalte die Mods im Reiter Mods ein.
  3. Klicke auf Apply mods. „N asset(s) patched." in der Activity-Liste heißt, die Mods sind angewendet.
  4. Klicke auf Start game.

Jedes Anwenden setzt zuerst zurück und wendet dann den ganzen angehakten Satz neu an, zweimal Anwenden ist also sicher. Anwenden schließt ein offenes Studio. Ist keine Mod angehakt, setzt Apply mods das Spiel zurück.

Status: Im Spiel bestätigt.

Keywords: mods anwenden, mods installieren, wie installiere ich mods, mod installieren, mods aktivieren, mods laden, mods benutzen, apply mods, install mods, enable mods, patch the game

Loader: Mods vor dem Anwenden prüfen (Check mod set)

Check mod set im Reiter Overview, oder Check im Reiter Mods, testet die angehakten Mods und schreibt nichts. Es prüft Asset-Namen, Konflikte zwischen Mods und die Sicherung. Typische Antworten:

  • „No conflicts. Ready to apply."
  • „N conflict(s); higher priority wins."
  • „Your selection is out of sync with the game.": Die angehakten Mods weichen von den angewendeten ab; Apply mods behebt das.
  • „Check failed — nothing was changed." mit dem Fehler, zum Beispiel zwei Mods, die dieselben Texturen ändern.

Keywords: mods prüfen, check mod set, mods testen, konflikt, konflikte, kompatibel, nicht synchron, vorab prüfen, check mods, conflicts, compatible mods

Loader: alle Mods zurücknehmen (Revert)

Revert nimmt jede Mod-Änderung zurück und stellt die originalen Spieldateien Bit für Bit aus den Sicherungen des Loaders wieder her. Seit 0.3.0 gehören dazu auch ersetzte Sound-Packs und Videodateien. Schließe das Spiel, klicke auf Revert und bestätige „Undo all mod changes and restore the original game files?". Die Meldung „The game is back to its original state." heißt, es ist fertig. Jedes Spiel hat eigene Sicherungen und ein eigenes Revert. Revert entfernt auch die Cvars, die der Loader in die default.cfg von The New Colossus geschrieben hat.

Letzter Ausweg, wenn die Sicherungen fehlen: in Steam Eigenschaften → Installierte Dateien → Spieldateien auf Fehler überprüfen.

Status: Im Spiel bestätigt.

Keywords: mods rückgängig machen, zurücksetzen, mods entfernen, mods deinstallieren, original wiederherstellen, spiel zurücksetzen, revert, undo mods, remove mods, uninstall mods, restore original

Loader: das Spiel starten (Start game)

Start game startet das Spiel über Steam, mit den Cvars aus Cheats & QoL und aus den angehakten Mods (deine Einstellungen sind schon gespeichert). Sind die angehakten Mods noch nicht in den Spieldateien, fragt es „Mods not in the game yet" mit Cancel, Start without und Apply and start: Wähle das letzte, sonst startet das Spiel mit dem alten Mod-Satz. Spielen.cmd tut dasselbe, ohne das Fenster zu öffnen.

Angewendete Mods bleiben in den Spieldateien, also hat auch ein Start aus der Steam-Bibliothek sie. Die Cvars, die der Loader als Startparameter übergibt, kommen nur mit Start game oder Spielen.cmd mit.

Keywords: spiel starten, spielen, starten, steam, Spielen.cmd, startet ohne mods, cvars fehlen, start game, launch game, play

Loader: Sicherungen und Sicherheitsnetz (Journal, _wolfsdk_backup)

Bevor er schreibt, sichert der Loader die Originaldaten von allem, was ein Anwenden ändert. Die Sicherungen liegen im Ordner base des Spiels: _wolfsdk_backup für The New Order, _wolfsdk_tnc für The New Colossus. Lösche sie nicht, solange Mods angewendet sind. Ein Write-Ahead-Journal lässt Revert ein Anwenden zu Ende bringen, das ein Absturz oder Stromausfall unterbrochen hat („Recovery needed" im Reiter Overview). Eine Sperre verhindert zwei gleichzeitige Anwende- oder Rücksetzläufe. Die Sicherungen brauchen etwa 1 GB frei auf dem Laufwerk des Spiels, bei The New Order je nach Mods bis etwa 3 GB.

Keywords: sicherung, sicherheitskopie, journal, _wolfsdk_backup, _wolfsdk_tnc, sicherheit, absturz beim anwenden, stromausfall, speicherplatz, backup, safety, disk space

Loader: was nach einem Spiel-Update zu tun ist

Das Spiel muss geschlossen sein, während der Loader Mods anwendet oder zurücksetzt. Nach einem Spiel-Update klicke zuerst auf Revert, dann wieder auf Apply mods. Der letzte Ausweg, wenn sich die Originaldateien nicht wiederherstellen lassen: in Steam Eigenschaften → Installierte Dateien → Spieldateien auf Fehler überprüfen, dann die Mods wieder anwenden.

Keywords: spiel update, nach dem update, aktualisierung, steam update, mods kaputt nach update, dateien überprüfen, game update, after update, verify integrity

Cheats & QoL: Cvars setzen (Cheats, Grafik, Komfort)

Der Reiter Cheats & QoL zeigt die vollständigen Cvar-Listen mit den Beschreibungen des Spiels: alle 3.186 einstellbaren Cvars der Engine-Registry von The New Order und alle 3.116 von The New Colossus. (Vor 0.3.0 zeigte The New Order nur die 31 gemessenen Tweaks; sie stehen weiter zuerst.) Suche nach Cvar-Name oder Beschreibung, wähle eine Kategorie oder nutze den Filter „Only set"; eine Anzahl wird angezeigt. An/Aus-Cvars haben Schalter, Zahlen und Text haben Wertfelder, Auswahlen haben Listen. Kleine Chips markieren „cheat" (The New Order: geht beim Start zusätzlich als +toggle mit) und „via default.cfg" (The New Colossus: kein Retail-Befehl, wird beim nächsten Anwenden oder Start über die default.cfg geliefert). Eigene Zeilen kommen ins Feld Custom cvars ganz unten, zum Beispiel pm_runspeed 400; alles wird beim Tippen gespeichert.

  • The New Order: beim Spielstart übergeben; keine Datei ändert sich. Cheat-Cvars gehen zusätzlich als +toggle mit, damit der Cheat-Reset beim Start sie nicht löscht.
  • The New Colossus: Cvars, die die Retail-Konsole annimmt, gehen als Startparameter; der Rest kommt beim nächsten Anwenden in die default.cfg. Revert entfernt sie.

Status: Im Spiel noch nicht bestätigt (der +toggle-Weg, der default.cfg-Weg und die Cvars von The New Order jenseits der 31 gemessenen Tweaks).

Keywords: cheats aktivieren, cvars, konsolenvariablen, einstellungen, sichtfeld, grafikeinstellungen, qol, fov, graphics settings

Cheats & QoL: Presets Ultra+, Clean Image und Photo Mode (Apply preset)

Presets gibt es nur für The New Colossus, im Reiter Cheats & QoL:

  • Ultra+ (17 Cvars): schärfere Texturfilterung, mehr Textur-Streaming, größere Sichtweiten für Decals, Schatten und Vegetation, besseres Wasser.
  • Clean Image (11): keine Tiefenunschärfe, keine Bewegungsunschärfe, keine chromatische Aberration, kein Filmkorn und keine Vignette, keine Auflösungsskalierung, dazu Nachschärfen.
  • Photo Mode (3): nur Screenshot-Qualität.

Wähle eines und klicke auf Apply preset: Es trägt die Werte ein, und sie werden sofort gespeichert; Start game oder Apply mods liefern sie aus. Reset nimmt die Werte zurück.

Status: Im Spiel noch nicht bestätigt.

Keywords: presets, voreinstellung, grafik, grafik verbessern, ultra, ultra+, clean image, photo mode preset, apply preset, reset preset, graphics preset, better graphics

Reiter Info: die Konsole von The New Order (Strg+^) und die Tasten F1–F4

In The New Order öffnet sich die Konsole mit Strg+^ (Strg und die Taste links neben der 1); keine Einstellung nötig. Der Reiter Info listet die Konsolenbefehle (mit Kopier-Knöpfen), Tastenbelegungen und Hinweise. Nützliche Befehle sind etwa toggle g_permaGodMode 0 1 (God-Mode), toggle g_infiniteAmmo 0 1, toggle g_freeCam 0 1 (freie Kamera), killMonsters und devmap. Der Loader belegt in The New Order außerdem vier Tasten: F1 God-Mode, F2 unendlich Munition, F3 freie Kamera, F4 HUD an/aus.

Status: Im Spiel noch nicht bestätigt (Konsole mit Strg+^, Cheat-Cvars über +toggle, Tasten F1–F4).

Keywords: konsole öffnen, konsole, new order konsole, strg+^, god mode, freie kamera, f1, f2, f3, f4, tastenbelegung, cheats tno, open console, ctrl+^, key binds

The New Colossus: keine Standard-F-Tasten (Sandbox Tools nehmen)

Der Loader gibt The New Colossus keine Standard-Belegung der F-Tasten. Eine Taste, die in diesem Spiel belegt ist, läuft auf einer eingeschränkten Konsolenstufe, auf der es toggle und noclip nicht gibt. Die Mods für The New Colossus nutzen stattdessen resourceExec <cfg> -s: Die Taste führt eine Config-Datei aus, die die Mod in die Archive des Spiels gelegt hat, und diese Datei darf die versteckten Befehle nutzen. Du belegst so eine Taste einmal in der Konsole des Spiels; Belegungen werden gespeichert. Für God-Mode und unendlich Munition nimm die Mod Sandbox Tools, für Screenshots die Mod Photo Mode.

Keywords: tnc tasten, f tasten, hotkeys, tasten belegen, tastenbelegung, bind, resourceExec, eingeschränkte konsole, f1 tut nichts, new colossus konsole, key bind, restricted console

Mitgelieferte Mods: welche Mods mit WolfSDK kommen

Beide ZIPs enthalten 24 Mods im Ordner mods: 8 für The New Colossus und 16 für The New Order. Alle sind aus, bis du sie anhakst.

  • The New Colossus: Sandbox Tools, Dev Menu Map Loading, Hidden Menu Options, Photo Mode, Explosive Pistol, Golden Pistol (Simple), Invulnerable (TNC), Gore Enhanced (TNC).
  • The New Order: fünf Beispiel-Mods, vier Gore-Mods, fünf Gameplay-Mods und zwei Sound-Mods.

Die meisten mitgelieferten Mods sind nur strukturell geprüft. Sofern die Beschreibung einer Mod im Loader nichts anderes sagt, gilt sie als im Spiel noch nicht bestätigt. Vier Mods, die ganze veränderte Retail-Dateien tragen, fehlen im Paket: Gore-Texturen, die Supersoldaten-Karte, die goldene Pistole mit Texturen und das Menü-Branding.

Keywords: mitgelieferte mods, enthaltene mods, welche mods, mod liste, eingebaute mods, verfügbare mods, shipped mods, included mods, which mods

Mod: Sandbox Tools (God-Mode, Notarget, unendlich Munition, alle Gegner töten)

Für The New Colossus. F6 schaltet God-Mode, Notarget und unendlich Munition um; F7 tötet alle Gegner. Hake die Mod an, klicke auf Apply mods, starte das Spiel und belege die Tasten einmal in der Konsole des Spiels (Belegungen werden gespeichert):

bind F6 "resourceExec snapdemo.cfg -s"
bind F7 "resourceExec snapedit.cfg -s"

Fehlerbehebung: der Loader startet nicht

  • Lege ihn nicht unter C:\Program Files ab; der Loader speichert seine Einstellungen im eigenen Ordner.
  • „Der Computer wurde durch Windows geschützt": Klicke auf Weitere Informationen → Trotzdem ausführen.
  • Das schwarze Fenster bleibt meist mit der Fehlermeldung offen. Derselbe Text steht in %LOCALAPPDATA%\wolfsdk\start.log.

Fehlerbehebung: eine Mod wirkt im Spiel nicht

  • Anhaken reicht nicht: Klicke auf Apply mods und starte dann das Spiel. Start game bietet an, vorher anzuwenden.
  • Prüfe das im Spielmenü gewählte Spiel; der Reiter Mods zeigt nur die Mods dieses Spiels.
  • Der Reiter Overview sollte „Mod set active · backup in place" und „In sync with the game" zeigen.
  • Mods für The New Colossus mit Tasten (Sandbox Tools, Photo Mode) brauchen ihre bind-Zeile, einmal in die Konsole des Spiels getippt.
  • Viele Mods sind im Spiel noch nicht bestätigt; lies die Beschreibung der Mod im Reiter Mods.

Fehlerbehebung: Apply mods oder Revert wird abgelehnt

  • Das Spiel läuft: Schließe es ganz und versuche es erneut.
  • Zu wenig Speicherplatz: Der Loader hält an, bevor er Mods schreibt (Mods, die angewendet waren, werden zurückgesetzt). Mach etwa 1 GB auf dem Laufwerk des Spiels frei, bei The New Order bis etwa 3 GB.
  • „Recovery needed" oder „Interrupted patch run - please revert.": Ein früherer Lauf wurde abgebrochen. Klicke auf Revert.
  • „Check failed — nothing was changed.": Lies den Fehler in der Activity-Liste; oft ändern zwei Mods dieselben Texturen.

Keywords: fehler beim anwenden, zurücksetzen fehlgeschlagen, abgelehnt, abgebrochen, speicherplatz, spiel läuft, unterbrochen, recovery needed, apply failed, revert failed, refused

Fehlerbehebung: Install map… wird abgelehnt

Grenzen des Loaders: nur Steam, deutsche Version, ein PC

  • Nur Steam-Versionen. Microsoft Store/Game Pass funktioniert nicht; GOG und Epic sind ungetestet.
  • Die deutsche, geschnittene Version hat andere Texturen. Skins aus der internationalen Version greifen dort vermutlich nicht; das ist ungeprüft.
  • Bisher auf einem PC getestet.
  • Der Loader kann keine Karten bauen; eine Kartendatei muss von jemandem kommen, der sie gebaut hat.
  • Hake nicht zwei Skins für dieselbe Waffe gleichzeitig an. Der Loader lehnt das nur von selbst ab, wenn beide dieselben Texturen ändern.
