This short report describes version 3 of an alias map bundle for Wolfenstein II: The New Colossus, based on the DLC map c2v1. The bundle keeps all original content unchanged, adds 143 new alias names and one visible change, a cyan-colored lobby light. Both archive header checksums were recalculated and the offline checks passed. It has not been installed or loaded in the game.

  • 6,985 original entries are kept byte-identical.
  • 143 new aliases and 140 rewritten resource paths were added, plus two new layer declarations.
  • The only visible test change is a cyan lobby light; the map geometry is unchanged.
  • The texture database from the original DLC 2 must be used when mounting.
  • Per-entry hashes and effects in the running game remain open.
