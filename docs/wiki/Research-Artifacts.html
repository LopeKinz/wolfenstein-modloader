In plain wordsIn einfachen Worten

This page lists the generated research files behind the wiki, such as rebuilt game archives, texture databases, screenshots and logs. They stay in the project repository rather than the wiki because many are several gigabytes and would exceed GitHub file-size limits. It gives file counts and sizes per research area and per file type. It is a catalog for orientation, not a research result.

  • In total 1,918 files with 7.4 GiB.
  • The largest share is 60 .resources archive files (3.8 GiB) and 28 .texdb files (2.5 GiB).
  • The biggest area is 'kitmap' with 1.6 GiB.
  • Every prose research note is in the wiki as its own page; only the large generated files stay out.

Technical detailsTechnische Details

Der technische Teil ist auf Englisch – so, wie er im Wiki steht. Unterstrichene Begriffe haben eine Erklärung auf Deutsch.

The Wiki includes every prose research note from re_probes as an English page. Large generated artifacts remain in the repository's re_probes/ tree: copying multi-gigabyte .resources, .texdb, images, archives, and temporary failures into a GitHub Wiki would duplicate data and exceed GitHub file-size limits.
