Primary DLC Test c02p0

Partly solvedTeilweise gelöst Original page in the GitHub wikiOriginalseite im GitHub-Wiki

In plain wordsIn einfachen Worten

This short page reports a runtime test in Wolfenstein II: The New Colossus with a self-made DLC (dlc_4) that claims the map c02p0 as its own. The game found the DLC and accepted its map entry. An archive with a wrong check value at header position +0x08 was clearly rejected as 'corrupt header', which is a hash check, not proof against DLC priority. Whether the DLC data actually wins over the original is still undecided, because the game ignored the start commands for loading a map.

  • The game reported 'found dlc id 4' and 'SearchDLC: found 4 dlcs'.
  • The DLC map entry for c02p0 (chunk 26) was accepted without syntax errors.
  • A wrong +0x08 header value leads to 'container chunk_26.resources has corrupt header'.
  • The original packagemapspec.json stayed bit-identical.
  • Next step: load via the menu or a save game, since +map, +exec and +loadGame were ignored at startup.

Technical detailsTechnische Details

Der technische Teil ist auf Englisch – so, wie er im Wiki steht. Unterstrichene Begriffe haben eine Erklärung auf Deutsch.

The test provided dlc_4 with a valid spec for game/wolf/c02/c02p0, chunkid: 26, basechunkid: 6, layer: -1, and refchunks: [1].

Verified:

  • The Retail Loader reported found dlc id 4 and SearchDLC: found 4 dlcs.
  • The primary DLC path is syntactically accepted; it is not the same as the pure refchunk path tested previously.
  • A container with a false header field +0x08 is explicitly rejected with container chunk_26.resources has corrupt header. This is a reproducible hash gate, not evidence against DLC priority.
  • base/packagemapspec.json remained bit-identical (SHA256 8E17EBD80C23F64FAE59C9188714C03DF69A0232284CFE7B6933ACC024570307).

Undecided: The direct Retail start ignores +map, +exec, and +loadGame before the menu; therefore, no new LoadMap section was generated in this run. The next true priority test must serve the Menu/Savegame load path and then compare only 100000 against 900000 in the log.
