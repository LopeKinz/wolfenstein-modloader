In plain wordsIn einfachen Worten

This page lists 550 of The New Order's cvars for graphics: the renderer (r_), the streaming of the giant megatexture (vt_), images and video. Each row shows the type, the default value, its status (cheat, normal, saved, start-up-only or read-only), the allowed range where the game defines one, and the developers' own description.

  • 550 cvars: r_ (428), vt_ (97) and a few smaller groups such as bink_ and image_.
  • 419 are cheats; settings the game saves in its config file, such as the graphics options, are not.
  • 75 have a declared range or a list of allowed values, for example image_filter.
  • How to set cheat cvars anyway is explained on the catalogue's start page.
