In plain wordsIn einfachen Worten

This page lists 953 of Wolfenstein II's cvars for graphics: the renderer (r_), the texture streaming (vt_), images and video playback. Each row shows the type, the default value, whether the normal console accepts it, and the developers' own description. Many are debug switches for the developers; 127 are open to the normal console.

  • 953 cvars: r_ (794), vt_ (114), image_ (15) and a few smaller groups.
  • 127 are open to the normal console and launch options, for example r_fullscreen and r_swapInterval (vsync).
  • The rest can only be set from a file run with resourceExec, as explained on the catalogue's start page.
  • Default values are the ones built into the program, not values from one play session.
