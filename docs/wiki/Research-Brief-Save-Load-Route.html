Mission: TNC Savegame/Menu Load Path

OpenOffen Original page in the GitHub wikiOriginalseite im GitHub-Wiki

In plain wordsIn einfachen Worten

This is an assignment, not a result. For Wolfenstein II: The New Colossus, it asks for a reproducible way to load an existing map from the menu or an existing save game. The goal is to check whether a self-made DLC archive overrides the original map, using a marker value (100000 vs. 900000). Earlier, the launch options +map, +exec and +loadGame had no effect before the menu.

  • Target map: c02p0, which an existing autosave refers to.
  • The self-made dlc_4 with its own map entry (chunkid 26) is already detected by the game.
  • Work must be read-only: no changes to the game installation and no game start.
  • The answer must be an exact load procedure or a clear negative result, including at least one check against a plausible but wrong syntax.

Ziel ist zu prüfen, ob ein selbst gebautes DLC-Archiv die Originalkarte überschreibt, anhand eines Markierungswerts (100000 gegenüber 900000). Die Startoptionen +map, +exec und +loadGame hatten vorher vor dem Menü keine Wirkung.

  • Zielkarte: c02p0, auf die ein vorhandener Autosave verweist.

Technical detailsTechnische Details

Der technische Teil ist auf Englisch – so, wie er im Wiki steht. Unterstrichene Begriffe haben eine Erklärung auf Deutsch.

Objective: Find a reproducible method to load an existing TNC map from the Retail Menu or an existing savegame, enabling measurement of the primary DLC Override Canary (100000 vs. 900000).

Context:

  • dlc_4 with the primary Mapspec for game/wolf/c02/c02p0, chunkid: 26, refchunks: [1] is detected.
  • +map, +exec, and +loadGame were not executed prior to the Menu via direct EXE start.
  • Existing Save: %USERPROFILE%\Saved Games\MachineGames\Wolfenstein II The New Colossus\base\savegame.user\<SteamID>\SLOT2\GAME-AUTOSAVE0, which reports c02p0 in its game.details.

Scope: Read-only or isolated work within Workspace files. Do not modify any further game installation and do not start the game process. Investigate configuration files, d01_*.txt, logs, EXE command strings, and existing documentation for correct syntax/sequence (loadGame, Savegame UI, startup command queue, map launch).

Acceptance: Exact, documented start/load procedure or clear negative finding; at least one counter-check against an obvious but incorrect syntax. Report exclusively to re_probes/agent_reports/save_load_route.md.
