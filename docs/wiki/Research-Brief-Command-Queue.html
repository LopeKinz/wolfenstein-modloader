Mission: Retail Command Execution

OpenOffen Original page in the GitHub wikiOriginalseite im GitHub-Wiki

In plain wordsIn einfachen Worten

This page is a short task description, not a result. When Wolfenstein II: The New Colossus was started with +map, +exec or +loadGame, nothing visible happened. The task is to explain this by reading the game's program file and configs, and to find a command queue or config file that runs after the engine has started.

  • Question: why did +map, +exec and +loadGame have no visible effect on a direct retail launch?
  • Goal: find a command queue or config file that reliably runs after engine start.
  • Text strings in the game file must be kept apart from commands that are actually registered.
  • No program patches, no starting processes and no changes to Steam files are allowed.

Die Aufgabe ist, das durch Lesen der Programmdatei und der Konfigurationen zu erklären und eine Befehlswarteschlange oder Konfigurationsdatei zu finden, die nach dem Start der Engine läuft.

  • Ziel: eine Befehlswarteschlange oder Konfigurationsdatei finden, die zuverlässig nach dem Engine-Start läuft.

Technical detailsTechnische Details

Der technische Teil ist auf Englisch – so, wie er im Wiki steht. Unterstrichene Begriffe haben eine Erklärung auf Deutsch.

Objective: Explain statically why +map, +exec, and +loadGame did not appear to execute visibly during a direct TNC retail launch, and identify a reliable command queue or config file that executes after engine initialization.

Sources: TNC-EXE located at <Steam library>\steamapps\common\Wolfenstein.II.The.New.Colossus, base/build.cfg, user configs/logs, local probe scripts, and documentation. No EXE patches, no process spawning, no Steam file modifications.

Search for exact string neighborhoods and known config ordering (exec, startup, autoexec, default.cfg, Wolfenstein II The New ColossusConfig.cfg, +set, com_*). Separate existing strings from actual registered retail commands.

Acceptance: Reproducible static explanation or a precise single next test with negative control. Report exclusively to re_probes/agent_reports/command_queue.md.
