In plain wordsIn einfachen Worten

This page is a generated overview of every kind of game file in Wolfenstein: The New Order: 203,843 assets in 105 types. For each type it shows how many exist, whether it is plain text you can edit or binary data, and what it controls, such as weapons, enemies, sounds or gore. 80 types are fully text and can be edited directly; 5 are mixed and 20 are binary. It also explains why another page counts the same types as "84 text, 21 binary": it uses a different counting rule, not a different measurement.

  • 203,843 assets in 105 types.
  • 80 types are pure text and directly editable, 5 mixed, 20 binary.
  • Largest types: sample (61,318), sound (43,782), voicetrack (30,627).
  • Weapons, enemies, damage, gore and materials are text; 3D geometry, animations and collision are binary.
  • The 'sample' type holds no audio data, only a descriptor; the tool's old label was corrected by hand.

Counting Rule

The 105 types split here triply: 80 TEXT, 5 mixed (sound, particle, renderProg, cuttableResource, file — Text Decls and their binary counterparts under the same type name), and 20 binary.

TNO-Modding-Surface.md refers to these same 105 types as "84 text, 21 binary". This is not a different measurement value, but a different counting rule: tools/survey_modding_surface.py knows no "mixed" class, but decides per type based on one sample (is_text()): over 95% printable characters in the first 4096 bytes. Four of the five mixed types end up on the text side, one on the binary — 80 + 4 = 84 and 20 + 1 = 21.

Whoever quotes the number should therefore specify which of the two rules is meant. "Directly editable without side effects" are the 80.

Note on generation. The block above is the output of tools/survey_engine.py. The line for sample has been manually corrected here: tools/survey_engine.py:45 continues to describe the type as "Raw audio data (Ogg Vorbis)", which Audio.md §3 refutes in all 61,318 entries. Until the line in the tool is updated, a rerun will bring back the error.
