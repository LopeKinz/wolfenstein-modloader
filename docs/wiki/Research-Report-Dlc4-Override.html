In plain wordsIn einfachen Worten

This report builds a modified archive for Wolfenstein II: The New Colossus that changes the DLC map 'Gestapo Office' (c2v1) under its original name, so a normal game load should pick it up. Exactly one entry, the map's entity list, is changed, with 49 edits: retyped enemies and pickups, swapped player starts and recolored lights. All offline checks and deliberate error tests pass. The edits have not yet been seen in the game.

  • Only one archive entry changes; all hash checks pass (7,127 of 7,127 entries, both header values).
  • The 49 edits are 4 enemies, 10 pickups, 33 lights and 2 player starts.
  • Edits were re-applied to the original map text, because a simple rename of the older alias version would have broken 20 entities.
  • All negative tests (missing edit, leftover alias name, unfinished archive) are caught.
  • Open: whether a save file keeps the old enemies and pickups; starting the chapter fresh is the cleaner test.

Technical detailsTechnische Details

Der technische Teil ist auf Englisch – so, wie er im Wiki steht. Unterstrichene Begriffe haben eine Erklärung auf Deutsch.

Task dlc4_override, 2026-09-24 (New build; the output of the aborted run was discarded and not used). Files: tools/build_dlc4_override.py, re_probes/dlc4_override/ (chunk_22.resources, manifest.json), this report.

Result

re_probes/dlc4_override/chunk_22.resources is the installed Custom Bundle (re_probes/entitypipe/base/chunk_22.resources, 7128 entries, sha256 a8da9e4e... = today dlc/dlc_0/base/chunk_22.resources) with exactly one modified entry: compfile:maps/game/dlc/c02/c2v1.entities (Index 873) which carries the 49 Manifest edits on the Retail text, without any alias names. All Gates green, all negative controls caught.

  • sha256 cadfbfce256d1a99ec1b4b151d801457b08cdb02724bc004c157d2eed06ab2f5, 151 702 019 bytes (same size as the source: +248 bytes payload disappear in alignment padding).
  • Reproducible: the new build is sha256-identical to the output of the aborted run.
  • Install as dlc/dlc_0/base/chunk_22.resources. Since dlc_0 wins according to runtime test (18:44) for game/dlc/c02/c2v1, a normal game load reads this file. Structurally valid; the edits under c2v1 are not yet seen in-game.

How built

  1. Retail text from entry 873 of the source bundle; its raw bytes are byte-identical to dlc/dlc_2/base/chunk_22.resources (verified).
  2. Edits from re_probes/entitypipe/manifest.json re-applied with functions from tools/build_custom_map.py (only imported): retype for 4 enemies + 10 pickups, swap_placement for the 2 player starts, light_color (color from manifest, LIGHT_MIN_INTENSITY) for 33 lights, in the order of author().
  3. tnccrypt.compfile_wrap, then idcl.Archive.rebuild + idclwrite.finalize (= idclwrite.write, called separately to allow the state before finalize to be probed as a negative control).

The alias text was not used as source: it deviates from Retail in 186 entities only by alias names, 19 of them with lowercase Kiscule-decl paths (c2v1_geo_Office -> c2v1_custom_geo_office), plus codex' cyan light c2v1_geo_lobby_detail_light_point_9_563923954 (no manifest edit). A replace("c2v1_custom", "c2v1") on the alias text would cause 20 entities to be incorrect -- the script measures this at every run.

Install (Master)

Delete first, then copy -- never write via a hardlink in dlc_2:

$G="<Steam library>\steamapps\common\Wolfenstein.II.The.New.Colossus"
Remove-Item "$G\dlc\dlc_0\base\chunk_22.resources"
Copy-Item re_probes\dlc4_override\chunk_22.resources "$G\dlc\dlc_0\base\"

Backtrack: the same two steps with re_probes\entitypipe\base\chunk_22.resources.

Worked, if the Gestapo Office Save loads with MountDlc: mounting ../dlc//dlc_0/base and you see the edits: red Lobby / green office, MP instead of Pretzel at (-3, -176), Elite soldiers in the first Lobby wave.

Open

  • Game State. A save file carries the entity state of your own entities; whether spawned enemies/pickups come from the save or from .entities (in which case Retypes only trigger on new spawns) is unspecified. Lights should be visible immediately; a fresh chapter start is the cleaner test.
  • The cyan light from the Alias bundle is intentionally not included.

Reproduction

python tools/build_dlc4_override.py     # ~2 min, each Gate printed, exit != 0 on FAIL

If a FAIL occurs after writing, the output will be cleared.
