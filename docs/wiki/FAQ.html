In plain wordsIn einfachen Worten

This FAQ answers what players and modders ask most about WolfSDK 0.2.0, the free mod loader and modding studio for Wolfenstein: The New Order and Wolfenstein II: The New Colossus (Steam versions on Windows). It covers downloading and installing, applying and reverting mods, game updates, other stores, the German version, custom maps and their DLC, both consoles, cheats, making your own mod and replacing textures. Each answer says whether a feature is confirmed in game, not yet confirmed in game, or held back.

  • Confirmed in game: applying and reverting mods with backups, installing a custom map, god mode and infinite ammo from Sandbox Tools, and maps loading from the developer menu.
  • Only the Steam versions work: Game Pass locks the game files, GOG and Epic are untested, and WolfSDK has been tested on one PC so far.
  • Custom maps for The New Colossus need the DLC The Freedom Chronicles, episode 2; mods, cheats and presets work with the base game.
  • In The New Colossus a bound key runs restricted, so mods bind a key to resourceExec instead; 0.2.0 sets no default F-key binds there.
  • Replacing sounds and videos is held back in 0.2.0; normal maps, the script editor, the presets and most shipped mods are not yet confirmed in game.

WolfSDK FAQ

Short answers to the questions players and modders ask most about WolfSDK 0.2.0, the mod loader and modding studio for Wolfenstein: The New Order and Wolfenstein II: The New Colossus. Step by step: WolfSDK Loader, WolfSDK Studio, Mod format, Modding Limits.

Keywords: FAQ, frequently asked questions, questions and answers, WolfSDK help, häufige Fragen, Fragen und Antworten

What is WolfSDK?

WolfSDK is a free mod loader and modding studio for Wolfenstein: The New Order (id Tech 5) and Wolfenstein II: The New Colossus (id Tech 6), for the Steam versions on Windows. Version 0.2.0 (2026-10-04) is the first public release.

It writes mods into the games' archives, keeps bit-exact backups and reverts everything with one click. It has a catalogue of the engines' own cvars for cheats and quality-of-life settings and installs custom maps for The New Colossus. The Studio part browses and replaces the games' assets and saves changes as mods.

An independent community project under the MIT license, not affiliated with MachineGames or Bethesda. No EXE patch, no DLL injection.

Keywords: what is WolfSDK, about, overview, mod loader, mod manager, modding tool, free, MIT, New Order, New Colossus, Wolfenstein 2, was ist WolfSDK, Modloader, kostenlos

What is the difference between WolfSDK Loader and WolfSDK Studio?

WolfSDK Loader is for players: tick mods, Apply mods, Start game, Revert, the Cheats & QoL page with presets, and Install map….

WolfSDK Studio is for modders: the Loader plus the Studio, which browses maps, videos, audio, textures and texts of both games, shows and exports the 17,315 models of The New Colossus in 3D and replaces BC1 textures, texts and decls. Each replacement is saved as a mod that the loader applies.

Only playing? Take the Loader. Making mods? Take the Studio; it contains the Loader. The Studio needs The New Colossus and opens from the loader's Studio page with Open Studio. Details: Loader, Studio.

Keywords: Loader vs Studio, difference, which download, which ZIP, player, modder, Open Studio, Unterschied, welcher Download, Spieler, Modder

Where do I download WolfSDK and how do I install it?

Download from the release page: https://github.com/LopeKinz/wolfenstein-modloader/releases/tag/wolfsdk-0.2.0. Players take WolfSDK-Loader-0.2.0.zip, modders WolfSDK-Studio-0.2.0.zip (it contains the Loader).

  1. Right-click the ZIP → Extract All… into a normal folder, e.g. Documents\WolfSDK. Not inside the ZIP view, not under C:\Program Files: the loader saves its settings in its own folder.
  2. Double-click WolfSDK.cmd. The loader finds the games through Steam; if not, use Choose folder… at the top right.

No Python install needed: Python 3.11 is bundled. Windows only, Steam versions of both games. The source code is in the repository folder modloader/.

Keywords: download, install, installation, setup, ZIP, extract, unzip, WolfSDK.cmd, Python, release, herunterladen, installieren, entpacken, einrichten

WolfSDK does not start or does not find my game – what now?

  • It says to extract the ZIP first: you started WolfSDK.cmd from inside the ZIP. Extract the ZIP into a normal folder.
  • The loader does not start: the black window usually stays open with the error message. The same text is in %LOCALAPPDATA%\wolfsdk\start.log. Send that text when you ask for help.
  • The game is not found: the loader looks for the games through Steam. Click Choose folder… at the top right and pick the game folder. Only the Steam versions are supported.
  • Pick the game: both games can be installed at once. The drop-down at the top right selects the game; the Mods page only shows the mods of the selected game.

Keywords: does not start, won't start, not found, game not detected, start.log, Choose folder, error, startet nicht, Spiel nicht gefunden, Fehler

Windows SmartScreen warns about WolfSDK.cmd – is that normal?

On the first start Windows may show "Windows protected your PC". Click More info → Run anyway. The README of the release describes exactly this step.

WolfSDK.cmd is a plain text batch file: you can open it in Notepad and read what it does. It starts the bundled Python from the python folder and opens the loader window.

The README does not cover warnings from other antivirus programs, and there is no tested advice for them yet. If one appears, report the program's exact message (see "Where do I report bugs or get help?").

How do I apply mods?

Close the game. Select the game at the top right, open the Mods page, tick the mods, click Apply mods, then Start game. Check mod set (Overview page) checks them without writing anything. Later, a double-click on Spielen.cmd ("play") applies the ticked mods if needed and starts the game.

Applying always reverts to the original first and then writes the whole ticked set, so you can apply again at any time. If two mods set the same value, the higher priority wins and a conflict is reported. Two mods that change the same textures are refused: tick one skin per weapon.

Status: applying and reverting with backups is Confirmed in game. Most shipped mods are only checked structurally (see each mod's description).

Keywords: apply mods, install mods, enable mods, activate mods, Apply mods, Start game, Check mod set, Spielen.cmd, Mods anwenden, Mods aktivieren, Mods installieren, anhaken

How do I undo mods and get the original game back?

Close the game and click Revert. It restores the game files bit for bit from the loader's backups. Each game has its own backups and Revert; select the game at the top right first. In The New Colossus, Revert also removes the Cheats & QoL lines the loader wrote into default.cfg. A custom map is not a mod: take it out with Remove map on the Overview page.

Do not delete the backup folders in the game's base folder (_wolfsdk_backup for The New Order, _wolfsdk_tnc for The New Colossus) while mods are applied. Last resort, in Steam: Properties → Installed Files → Verify integrity of game files.

Status: Revert is Confirmed in game.

Keywords: undo mods, revert, uninstall mods, remove mods, restore original, reset, rollback, disable mods, verify integrity, Mods entfernen, rückgängig, zurücksetzen, Original wiederherstellen

What do I do after a game update?

Best: click Revert before Steam updates the game. If the game already updated while mods were applied, click Revert first and then Apply mods again.

The loader compares the archives with its backup. If an update changed them, it refuses to write and says that a file "no longer matches the backup. Game update?". It does not write over files it does not recognise.

If Revert cannot finish after an update, let Steam repair the game (Properties → Installed Files → Verify integrity of game files) and report the message in Discord. Before you apply again, check your mods with Check mod set: it shows whether their assets and paths still exist.

Keywords: game update, game updated, what now, Steam update, patch, after update, broken after update, no longer matches the backup, Spiel-Update, Update, nach dem Update, aktualisiert

Does WolfSDK work with Game Pass, GOG or Epic?

No for Game Pass, untested for GOG and Epic. WolfSDK supports the Steam versions of both games only.

  • Microsoft Store / Xbox Game Pass: does not work. That version locks the game files, so the loader cannot write mods.
  • GOG and Epic: untested. The loader finds the games through Steam and starts them through Steam (steam://rungameid/...), so Start game is built for the Steam version.

So far WolfSDK has only been tested on one PC with the Steam versions.

Keywords: Game Pass, Xbox, Microsoft Store, GOG, Epic, Epic Games, Steam only, which version, supported platforms, other store, funktioniert das mit GOG, nur Steam, Plattform

Does WolfSDK work with the German (censored) version?

Probably only partly. The German cut version of the games has different textures. Skins and texture mods made from the international version probably do not apply there. This is unverified: nobody has tested WolfSDK with the German version yet.

Mods that change values (weapons, enemies, cvars) are not affected by the textures, but they are untested on the German version too. If you try it, a report in Discord helps.

Do I need a DLC? Which DLC do custom maps need?

Only for custom maps. Mods, Cheats & QoL and the presets work with the base game.

A custom map for The New Colossus needs the DLC The Freedom Chronicles, episode 2: the custom map takes the place of the DLC map c2v1 and is loaded in the game through that episode. Without that DLC episode, an installed custom map cannot be started this way. Ways to load maps without the DLC exist only as research so far (Research-Report-R3-Mapselfcontained).

The New Order needs no DLC for anything in WolfSDK.

How do I install a custom map in The New Colossus?

On the Overview page under Quick actions, click Install map… and choose a finished map file (chunk_22.resources). The loader sets it up as its own DLC folder dlc\dlc_0. Remove map takes it out again. If mods are applied, the loader usually asks for a Revert first.

The loader cannot build a map: the file has to come from someone who built it. The map replaces c2v1 and needs the DLC The Freedom Chronicles, episode 2.

Status: installing a custom map is Confirmed in game. Background: TNC Custom Map Status.

Keywords: custom map, install map, Install map…, Remove map, dlc_0, chunk_22.resources, new map, own map, Karte installieren, eigene Karte, Map installieren

How do I use the developer menu in The New Colossus?

Tick the mod Dev Menu Map Loading, click Apply mods and Start game, then open the developer menu. Its map entries load maps again; each entry runs devmap. Confirmed in game. The 126 restored developer start points are Not yet confirmed in game.

The entry WolfSDK: Mod test map (c2v1 with 11 weapons and 8 enemies for trying out mods) loads (Confirmed in game), but the map file is not in the 0.2.0 package: the entry only works once the test map is installed in dlc\dlc_0.

The mod Hidden Menu Options adds a main menu entry for the developer menu (Not yet confirmed in game). More: TNC Dev Menu.

Keywords: developer menu, dev menu, devmenu, devmap, load map, level select, mod test map, Dev Menu Map Loading, Hidden Menu Options, Entwicklermenü, Dev-Menü, Karte laden

How do I open the console in The New Order?

Press Ctrl+^: Ctrl plus the key left of 1. A plain ^ or ~ does nothing, and com_allowConsole does not open it. Not yet confirmed in game (read from the code).

A bare name value on a cheat cvar is refused ("CANNOT be set in retail!"). toggle force-sets it, e.g. toggle g_permaGodMode 0 1. The loader sends cheat cvars from Cheats & QoL as +toggle at start, so the cheat reset does not wipe them (Not yet confirmed in game).

god, noclip, notarget, give and spawn do not exist in The New Order. Use toggle g_permaGodMode 0 1 and toggle g_freeCam 0 1. The command list is on the System & Info page (sidebar: System & Info).

Keywords: console, open console, The New Order console, TNO console, Ctrl+^, toggle, cheat cvars, god, noclip, Konsole öffnen, Konsole TNO, Cheats

How does the console work in The New Colossus?

The New Colossus has a real console in the retail game, but it accepts only 34 of 234 commands and 304 of 3,256 cvars; everything else answers "Unknown command". Research opened it with the start argument +com_enableDeveloperMode 1 (Developer Mode).

Non-exposed commands (God, Notarget, g_infiniteAmmo 1) run from a file executed with resourceExec <file> -s. The Sandbox Tools and Photo Mode mods replace unused config files for this, and you bind a key to resourceExec. Confirmed in game for God and infinite ammo.

give, spawn, noclip and lowercase god do not exist in this game. Details: TNC Console Unlock.

Keywords: console, The New Colossus console, TNC console, restricted console, Unknown command, resourceExec, developer console, Konsole TNC, Entwicklerkonsole, Befehl unbekannt

Why do my F-key binds not work in The New Colossus?

A bound key in The New Colossus runs at the restricted console level (34 commands), where toggle, noclip and the cheat commands do not exist. A bind like bind F1 "toggle g_permaGodMode 0 1" does nothing. So WolfSDK 0.2.0 sets no default F-key binds there (0.1.0 did; they never worked).

The mods bind a key to resourceExec <cfg> -s instead: it runs a loader-replaced config file unrestricted. Apply the mod, then bind once in the console (binds are saved):

  • Sandbox Tools: bind F6 "resourceExec snapdemo.cfg -s", bind F7 "resourceExec snapedit.cfg -s"
  • Photo Mode: bind F8 "resourceExec default_snap.cfg -s"

The New Order gets default F1–F4 binds (Not yet confirmed in game).

How do I get god mode, infinite ammo and other cheats?

The New Colossus: tick Sandbox Tools, Apply mods, then bind the keys once (see the F-key question). F6 toggles god mode, Notarget and infinite ammo; F7 kills all enemies. God mode and infinite ammo: Confirmed in game. Notarget and F7: Not yet confirmed in game.

The New Order: the Cheats & QoL page sets cvars at start (e.g. g_permaGodMode), F1–F4 get default binds, and the mod Cheats - Health and Ammo gives the campaign the values of the 999 mode. All Not yet confirmed in game.

Cheats & QoL lists 3,116 cvars for The New Colossus and 3,194 for The New Order. Both games are single player.

Keywords: cheats, god mode, godmode, infinite ammo, unlimited ammo, noclip, notarget, kill all enemies, Sandbox Tools, Cheats & QoL, unendlich Munition, Gottmodus, unverwundbar

How do I make my own mod?

Two ways:

  • With the Studio (no code): download WolfSDK-Studio-0.2.0.zip, open the Studio page, click Open Studio, pick a texture, text or decl and replace it. The Studio saves the change as a mod in the mods folder. Then tick it on the Mods page, Apply mods, Start game. Guide: WolfSDK Studio.
  • By hand: create a folder in mods with a mod.json that lists the changes, for example one value of a weapon decl. Every field with real examples: Mod format. Which decls and paths exist: Modding Guide.

Check a new mod with Check mod set before you apply it.

Keywords: make a mod, create a mod, own mod, write a mod, first mod, modding tutorial, mod.json, Studio, eigene Mod, Mod erstellen, Mod schreiben, Mod machen

How do I replace textures or sounds?

Textures: in the Studio (WolfSDK Studio package), pick a texture and replace it with a PNG; the Studio saves it as a mod. BC1 textures of The New Colossus take a PNG of any size. Normal maps (BC5) need a PNG of exactly the texture's size, green channel in DirectX convention (Not yet confirmed in game). During research, a custom BC1 pistol skin was seen in a running game.

Sounds and videos: Held back in 0.2.0. The Studio refuses those replacements for now, because Revert does not yet restore replaced sound packs and video files. It comes in an update.

Texts and decls can be replaced in the Studio too. Do not tick two skins for the same weapon at once.

Is WolfSDK safe? Is my game safe with mods?

Yes. WolfSDK is built so that every change is safe to undo with Revert:

  • Before the first write it backs up the original data of everything it changes, including a full copy of every archive it rewrites.
  • A write-ahead journal records each operation. After a crash or a power cut the loader detects the unfinished operation, and Revert can finish it. A file lock prevents two operations at once.
  • It refuses to write while the game runs and stops before writing when the disk is too full.
  • Both games are single player: mods and cheats affect no one else.

Last resort: Steam's Verify integrity of game files. Tested on one PC so far, so back up your saves to be safe (next question).

Do I need to back up my save games?

Yes, once before you start. Copy the folder %USERPROFILE%\Saved Games\MachineGames somewhere safe. The loader backs up the game files, not your saves, and it has not been checked for every mod whether old saves load cleanly with and without it.

The game file backups need about 1 GB free on the game's drive; with The New Order it can be up to about 3 GB, depending on the mods. If there is not enough space, the loader stops before it writes anything.

Which WolfSDK features are confirmed in game?

Confirmed in game (WolfSDK 0.2.0):

  • Applying and reverting mods with backups.
  • Installing a custom map (Install map…).
  • Sandbox Tools: god mode and infinite ammo.
  • Dev Menu Map Loading: the developer menu runs devmap and loads the map.
  • WolfSDK: Mod test map loads.

Held back: replacing sounds and videos, because Revert does not yet restore them.

Keywords: confirmed in game, tested, what works, working features, status, verified, proven, im Spiel bestätigt, getestet, was funktioniert

Which WolfSDK features are not yet confirmed in game?

Not yet confirmed in game (WolfSDK 0.2.0):

  • The 126 restored developer start points.
  • Sandbox Tools: Notarget and F7 (kill all enemies).
  • Hidden Menu Options.
  • The presets Ultra+, Clean Image and Photo Mode.
  • The Photo Mode mod (F8).
  • The New Colossus: cvars written into default.cfg.
  • The New Order: the console with Ctrl+^, cheat cvars via +toggle, the F1–F4 binds.
  • Studio: normal maps (BC5) and the Kiscule script and mission editor.
  • Most other shipped mods: they are only checked structurally. Unless a mod's description says otherwise, treat it as untested in game.
