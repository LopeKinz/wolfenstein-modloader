Research Task: DLC-/Patch Container and Priority

OpenOffen Original page in the GitHub wikiOriginalseite im GitHub-Wiki

In plain wordsIn einfachen Worten

This page is a task description for Wolfenstein II: The New Colossus. The game already recognises a custom DLC folder, but an extra archive added next to the base archives lost out because the base archive held files with the same names. The worker was asked to study the game's package lists and DLC and patch layouts to find out whether a DLC or patch container can be mounted as the primary source instead. Only a read-only study with testable proposals was requested; the game was not to be started.

  • A custom dlc_4 is detected by the game ('found dlc id 4').
  • An extra reference chunk 26 was mounted but lost against base chunk_1 because of identical names.
  • This rules out only that one route, not a primary DLC or patch route.
  • Deliverable: real examples from the retail files and a list of what needs one controlled test.

Technical detailsTechnische Details

Der technische Teil ist auf Englisch – so, wie er im Wiki steht. Unterstrichene Begriffe haben eine Erklärung auf Deutsch.

Goal: Determine clearly whether a dedicated DLC-/Patch container can be mounted as the primary source for a map/asset group, instead of merely existing as a refchunk alongside a Base Chunk.

Context:

  • Custom dlc_4 is recognized by the game (found dlc id 4, SearchDLC: found 4 dlcs).
  • An additional Base refchunk 26 was successfully mounted but lost against Base chunk_1 due to identical (type,name).
  • This refutes only this Refchunk path, not necessarily a primary DLC-/Patch path.
  • Do not start; do not modify Steam files.

Investigate: Existing packagemapspec.json, packagechunklist.json, DLC layouts, patch_N structures, and local tools/documentation. Search for specific fields (basechunkid, layer, patchlevel, Mapspec entries, Chunk IDs) and derive possible, testable primary paths.

Acceptance:

  • Exact examples from Retail files with paths/fields.
  • Statement of what is thereby secure and what requires a controlled single test.
  • No changes except an optional custom report re_probes/agent_reports/dlc_primary.md.
