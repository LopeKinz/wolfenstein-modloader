Search Task: Loose Assets and External Load Paths

OpenOffen Original page in the GitHub wikiOriginalseite im GitHub-Wiki

In plain wordsIn einfachen Worten

This is an assignment, not a result. It asks a worker to search Wolfenstein II: The New Colossus for ways to load modified files from outside the game's original archives, using only read access. Sources are program strings, config files, logs and existing notes about loose assets, developer mode, reloading definitions, workshop or mod folders. It notes that the DLC search path setting 'resource_dlcDbgSearchPath' is an unknown command in the retail game.

  • The game must not be started and no file in the Steam installation may be changed.
  • A self-made DLC folder is already recognized by the game.
  • Only verifiable candidates with the exact string or path and where it was found are accepted.
  • Each candidate must be labeled as confirmed, plausible or refuted.

Technical detailsTechnische Details

Der technische Teil ist auf Englisch – so, wie er im Wiki steht. Unterstrichene Begriffe haben eine Erklärung auf Deutsch.

Goal: Find exclusively read-accessible modding paths for Wolfenstein II: The New Colossus where modified files can be loaded outside the original base containers.

Context:

  • The retail installation is located under <Steam library>\steamapps\common\Wolfenstein.II.The.New.Colossus.
  • A dedicated DLC folder is recognized, but resource_dlcDbgSearchPath is an unknown command in this retail version.
  • The engine/game process must not be started. Do not modify any file within the Steam installation.

Investigate: EXE strings, existing configurations, logs, and local tools/documentation for specific Cvars, command-line parameters, or file paths related to Loose Assets, Dev-Mode, Decl-Reload, Workshop, or mod directories.

Acceptance Criteria:

  • Only verifiable candidates with exact string/path and source location.
  • Clearly distinguish between confirmed, plausible, and refuted items.
  • No modifications except optionally a single exclusive report at re_probes/agent_reports/loose_assets.md.
