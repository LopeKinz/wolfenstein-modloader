In plain wordsIn einfachen Worten

This page lists the remaining 1,359 of Wolfenstein II's cvars: the engine core (com_), sound (s_), network (net_), input, menus and UI (swf_, menu_), resource loading and the leftover SnapMap editor settings (snapedit_). Each row shows the type, the default value, whether the normal console accepts it, and the developers' own description.

  • 1,359 cvars, the largest groups being snapedit_ (185), net_ (130), com_ (107), swf_ (70) and resource_ (56).
  • 142 are open to the normal console and launch options, for example the volume settings s_volume and s_volume_music.
  • Prefixes with fewer than 10 cvars share one table at the end of the page.
  • How to change the others is explained on the catalogue's start page.
