Status of a custom map prototype for Wolfenstein II (TNC). It installs a copy of the DLC map Gestapo Office (c2v1) under a new name as an extra DLC bundle, and prepares an edited save file to load it. The game starts stably with the bundle, but loading the map through the save has not been confirmed, and the world geometry is not replaced yet.

  • The bundle contains all 6,985 original entries and shares the original textures.
  • Earlier save attempts showed 'File Corrupt'; version 2 also fixes the map name inside checkpoint.dat.
  • According to this page, map and devmap report 'unknown command' in the console.
  • A patch to show the map in the developer menu crashed the game at startup and was removed.
  • The original saves are backed up and can be restored at any time.

Stand eines Prototyps für eigene Karten in Wolfenstein II (TNC). Er installiert eine Kopie der DLC-Karte Gestapo-Büro (c2v1) unter neuem Namen als zusätzliches DLC-Paket und bereitet einen bearbeiteten Spielstand vor, der sie laden soll. Das Spiel startet mit dem Paket stabil, aber das Laden der Karte über den Spielstand ist nicht bestätigt, und die Weltgeometrie ist noch nicht ersetzt.

  • Das Paket enthält alle 6.985 Originaleinträge und nutzt die Original-Texturen mit.
  • Frühere Versuche zeigten „File Corrupt“; Version 2 korrigiert zusätzlich den Kartennamen in checkpoint.dat.
  • Laut dieser Seite melden map und devmap in der Konsole „unknown command“.
  • Ein Patch, der die Karte im Entwicklermenü zeigen sollte, ließ das Spiel beim Start abstürzen und wurde entfernt.
  • Die Original-Spielstände sind gesichert und jederzeit wiederherstellbar.

Technical detailsTechnische Details

Der technische Teil ist auf Englisch – so, wie er im Wiki steht. Unterstrichene Begriffe haben eine Erklärung auf Deutsch.

What is Installed

  • Target Game: Wolfenstein II: The New Colossus (TNC)
  • Test Map: DLC2, game/dlc/c02/c2v1 (Agent Silent Death / Gestapo Office)
  • Alias: game/dlc/c02/c2v1_custom
  • Bundle: dlc/dlc_4/base/chunk_22.resources
  • Textures: Hardlink to DLC2 chunk_22.texdb, ensuring all unchanged texture keys remain valid.
  • Current Probe Build: Complete hardlinks to Retail DLC2 Chunk 22 (6,985 entries), no longer the reduced 243-entry candidate.
  • A targeted devmapinfo.json patch (showInDevMenu=true) was built in isolation but caused a crash on startup and has been discarded; the stable Full-Retail Bundle has been restored.
  • Runtime Mods: Gore-CVars and g_demoDevMode=1.
  • Save Candidate v2 additionally patches the NUL-terminated map entry in checkpoint.dat; v1 left this Retail path intact and was therefore rejected as "File Corrupt".

Save Registration

The save candidate now resides in the actual used Freedom Chronicles subfolder (UI Progression Slot 1):

%USERPROFILE%/Saved Games/MachineGames/Wolfenstein II The New Colossus/base/savegame.user/<SteamID>/SLOT0/FC2-WOLF0

Only the map/layer strings in checkpoint_mapstart.dat and game.details have been changed; the previous SLOT2 structure is preserved under:

re_probes/save_backups/SLOT0_before_c2custom (additionally, SLOT2_before_c2custom remains intact)

Testing

The process starts stably with the installed Bundle. The first attempt in Slot 3 resulted in "File Corrupt" due to the incorrect slot; the unchanged Slot 3 has been restored. A second attempt in Slot 1 with v1 also remained corrupt without .verify, because checkpoint.dat still contained the Retail path. v2 corrects this entry and passes tools/savehash.py pruefen; additionally, the current Full-Retail Probe Build uses correct patchlevel/refchunks and all chunk entries. The runtime test must still be confirmed by loading the top Gestapo Office save into Progression Slot 1. Success criteria: Load without Map-Not Found/Crash and visible entry into the map.

The direct Developer Command Test is negative: both map and devmap report "unknown command" in the TNC Retail Build. A devmapinfo payload patch for showInDevMenu=true caused a startup crash and was removed from the game folder. The last Steam launch requirement additionally failed due to Steam's message "no licenses"; this is an external license state, not a Mod/Save error.

Known Limitations

  • The console does not know the map command.
  • devmap is also unknown in the Retail Command set; Developer Mode CVars do not activate the removed commands.
  • The prototype does not yet replace world geometry; it validates the alternative map path and DLC bundle resolution.
  • For a truly new Map ID, IDCL identity, internal asset references, save/menu registration, and potentially PVS/Navmesh must be adjusted together.
  • The original saves can be restored at any time from the mentioned backup.
