WolfensteinModloader

We take the Wolfenstein games apart to learn how their files work, and write down everything we find, so anyone can mod them. Wir nehmen die Wolfenstein-Spiele auseinander, um zu verstehen, wie ihre Dateien funktionieren, und schreiben alles auf, was wir finden – damit jeder sie modden kann.

What this isWorum es geht

Games keep their weapons, enemies, maps and pictures in large packed files. Nobody outside the studio documented how those files are built, so we find out ourselves. That work is called reverse engineering.

Spiele bewahren Waffen, Gegner, Karten und Bilder in großen gepackten Dateien auf. Außerhalb des Studios hat niemand dokumentiert, wie diese Dateien aufgebaut sind – also finden wir es selbst heraus. Diese Arbeit heißt Reverse Engineering.

Everything we learn goes into the wiki: how the archives are packed, how a weapon is described in a Decl, which limits the engine sets, and which ideas turned out to be wrong.

Alles, was wir lernen, steht im Wiki: wie die Archive gepackt sind, wie eine Waffe in einer Decl beschrieben wird, welche Grenzen die Engine setzt und welche Ideen sich als falsch erwiesen haben.

Modding without the command lineModden ohne Kommandozeile

Wolfenstein Studio is the desktop app this project is building. It turns the research on this page into buttons: open the game files, change what you want, play, and undo it again.

Wolfenstein Studio ist die Desktop-App, an der dieses Projekt baut. Sie macht aus der Forschung auf dieser Seite Knöpfe: Spieldateien öffnen, ändern, was du willst, spielen – und es wieder rückgängig machen.

  • Look inside the game. Browse the archives of both games and read Decls, texts and images.
  • In das Spiel hineinsehen. Die Archive beider Spiele durchsuchen und Decls, Texte und Bilder lesen.
  • Change values. Damage, magazine size, enemy health – edit them and save the result as a mod.
  • Werte ändern. Schaden, Magazingröße, Gegnerleben – bearbeiten und als Mod speichern.
  • Install safely. Every change is backed up and can be undone with one click.
  • Sicher installieren. Jede Änderung wird gesichert und lässt sich mit einem Klick zurücknehmen.
  • Spot conflicts. See when two mods change the same value before you start the game.
  • Konflikte erkennen. Sehen, wenn zwei Mods denselben Wert ändern, bevor das Spiel startet.

In development. The release date and final features will be announced here.

In Entwicklung. Termin und endgültiger Funktionsumfang werden hier bekanntgegeben.

The two gamesDie zwei Spiele

The New Order

2014, id Tech 5

The best-measured part of the research. Archives, Decls, images, sound and save games are understood well enough to change them safely.

Der am besten vermessene Teil der Forschung. Archive, Decls, Bilder, Ton und Spielstände sind so gut verstanden, dass man sie sicher ändern kann.

II: The New Colossus

2017, id Tech 6

Harder to open: encrypted files and fingerprinted archives. A first custom map has been played in the game; documenting it and building bigger maps comes next.

Schwerer zu öffnen: verschlüsselte Dateien und Archive mit Fingerabdrücken. Eine erste eigene Karte wurde bereits im Spiel gespielt; als Nächstes kommen die Dokumentation und größere Karten.
